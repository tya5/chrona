# Chrona Design Documentation

| Directory | Contents |
|---|---|
| `specification/` | Numbered normative specifications (`00`–`14`) and supplemental design specifications |
| `decisions/` | Architecture Decision Records (ADRs) |
| `federation/` | Cross-repository federation research and design |
| `planning/` | Documentation, remediation, and coverage plans |
| `reviews/` | Point-in-time readiness and final review records |
| `schemas/` | Machine-readable structural schemas |
| `fixtures/` | Canonical examples, positive/negative conformance cases, and runners |

Start with [the documentation plan](planning/design-documentation-plan.md), then read
the numbered specifications in order. Review records describe their stated historical
scope; they do not supersede the corresponding normative specification.
