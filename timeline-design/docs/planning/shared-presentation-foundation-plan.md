# 共通表現基盤の設計・実装計画

**状態:** 2026-09-20 G0設計完了・公開。ランタイム変更なし。
**根拠:** ADR-0019、仕様30。A〜Dは受入イメージであり、個別rendererを要求しない。

## 優先順とゲート

| 段階 | 対象 | 終了条件 |
|---|---|---|
| G0 全体設計閉包 | G1〜G4の所有者・内部IR・wire schema・移行・共通計測/配置・診断・fixtures | 下記チェックリストが全件閉じる。設計を公開してからG1へ |
| G1 既存契約の是正 | 設定消費、文字計測、実績/差分の意味保持、共通Scene経路 | 設定変異で消費を検証。未知・非対応値は明示診断。既存P1〜P5未完了項目との対応表を更新 |
| G2 A/Dの共通表現 | 月/週軸、近接ラベル、計画/実績の表示方式、group×facet色 | ASTERと異なるプロジェクトで同じ機構を使用。任意ID・長文・日本語・viewport変更の検証 |
| G3 注釈と説明帯 | 共通アンカー/本文領域/leaderによる注記とpoint説明 | 少なくとも二用途を同じ実装で通す。一般化できない装飾は除外し、特例で成立させない |
| G4 レーン配置 | stable stackingとラベル・接続の協調 | G2/G3と同じ計測/障害物/経路機構で成立する範囲だけ受入 |

G0でG3/G4の境界も決めるため、後から基礎モデルを作り直すことを避ける。
有限の方式で成立しない図は、サポート範囲外として仕様・診断・fixtureへ残す。
難しい表現のために探索器やDSLを無制限に拡張しない。

## 共通受入行列

| 観点 | 必須ケース |
|---|---|
| 用途 | バー名、終了日、作業注記、計画ゲート説明、表セル |
| 事実保持 | 計画/実績/差分/依存edge集合は装飾・配置変更で不変 |
| 参照 | unknown ID、非表示対象、実績欠測、span/point endpoint不一致、同対象の複数投影 |
| 注釈 | semantic/presentationを区別。leaderはdependencyにならない |
| 幾何 | 長文、太字、日本語、箱overflow、文字障害物、経路不能、非常に狭いviewport |
| 再現性 | 同じ閉包から別プロセスでも同じScene/出力。入力資産はversion/hash固定 |
| 一般性 | object IDを全置換し、チーム数・日付・文言を変更。別プロジェクトでも特殊分岐不要 |
| スキーマ | 未使用設定、未知値、二重所有、違法なfacet/role対応を検出 |
| 境界 | 専用実装を要する装飾は不採用。実現可能な図すべてを解くとの保証はしない |

画像比較だけで合格にしない。構造・意味・幾何・画像を別々に報告する。
既存の127テストPASSを新機能や設計完了の証拠に流用しない。

## 公開と既存作業の保護

設計段階と各実装段階の終了時に、対象差分だけをレビューしてnon-force公開する。
既存の未コミット変更や過去に公開済みの作業を巻き込まない。
設計変更が必要な場合は関連実装を一時中断し、影響する仕様・schema・fixture・
計画・受入条件を先に整合させる。画像の再現度のために契約を例外化しない。
