# Changelog

All notable changes are recorded here. Chrona follows semantic versioning once a
public release contract is declared; the current package remains alpha.

## Unreleased

### Changed

- Reorganized documentation, schemas, conformance, examples, tests, and source code
  into a product-oriented open-source layout.
- Grouped Python modules by semantic owner and decomposed presentation code into
  model, layout, scene, renderer, and review packages.
- Packaged runtime schemas, built-in presentation settings, and font metrics for
  installed-wheel execution.
- Added contributor, security, issue, pull-request, CI, and final acceptance guidance.

### Known limitation

- No license has been selected. The repository is source-available for inspection but
  must not be treated as licensed for reuse until a `LICENSE` file is added.
