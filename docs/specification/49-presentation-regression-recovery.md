# Issue #49 presentation regression recovery specification

## Failure ownership

| Failure family | Authoritative owner | Recovery rule |
| --- | --- | --- |
| Table cell overlap | Layout measurement + Scene table placement | Measure each normalized column's maximum content width and derive non-overlapping table cell origins from that measured vector. View remains the column author. |
| Shared tracks, fixed mark size, same-row ports | View row projection + Scene | Preserve explicit member identity/track and endpoint ports; routing excludes only endpoint rows. |
| Group header | View grouping + Scene + Theme | A nonzero declared group-header metric reserves a header and emits labelled header primitives in the `groupHeader` role. |
| As-of, closure shading, axis bands | Actual/Project + View + Scene | Actual `asOf`, Project calendars, and View axis selection are the sole facts; Scene emits only selected primitives. |
| Legend swatches | Detail profile + Layout + Theme + Scene | A declared legend slot and entries produce role-derived swatch/text pairs. |
| Annotation leader | View annotation + Layout slot + Scene routing | Anchors resolve to one projected mark; bounded leaders diagnose only when geometry is unavailable. |
| Gallery duplicate validation | CLI closure boundary | Reject duplicate scheme IDs before resolving/rendering any gallery member. |
| Snapshot capture identity | Immutable storage | A revision-only reference derives and publishes its computed content identity; explicit inconsistent identities reject. |
| Example evidence | Materializer | Public materializer is the only writer; every manifest slide selects its declared context and checks bytes. |

## Compatibility

Existing Views without an optional axis/legend/group-header choice keep current output. No settings, theme fallback, renderer example branch, or hand-authored generated SVG is introduced.

## Acceptance

All 13 named tests pass with their original assertions or stronger replacement assertions, Controller Z is regenerated by the public materializer, and all example manifests reproduce.
