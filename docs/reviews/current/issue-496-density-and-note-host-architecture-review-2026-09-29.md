# #496 density and note-host architecture review

**Decision:** accept the [correction](../../design/issue-496-density-and-note-host-correction-2026-09-29.md) before Slice 1 publication or Slice 2 implementation. Reviewed against [Spec 64](../../specification/64-portable-icon-catalogs.md), [Spec 07](../../specification/07-style-and-theme.md), [Spec 08](../../specification/08-scene-and-rendering.md), the [#496 selected design](../../design/issue-496-theme-asset-catalogues-design-2026-09-28.md), and the [#466 final acceptance](issue-466-annotation-placement-final-acceptance-review-2026-09-29.md) on public `main` `50aa4d69`.

Importer owns the finite source-to-canonical normalization and reproducible density measurement. Its fixed sampling proxy is explicit, so a BVH or grid index is an implementation detail and cannot alter canonical bytes. Layout still owns completed tile placement, Scene carries the normalized quadratic geometry and effective paints, and SVG/PNG still derive from that single Scene. Density does not authorize an adapter to approximate or recolor geometry. The #466 same-source note-text ground remains flat and opaque; removing only `annotation-note-box.pattern` prevents Theme admission from contradicting Scene's required contrast host. Other pattern roles retain the selected #496 pairwise paint gate. No v0.3 catalogue, v0.11/v0.12 Theme, v0.6 Scene, or public example changes in this design publication.

**Implementation gate:** test full-span arcs, stroke boundary ties, wrapped line/circle coverage, non-square rotated tiles, and 1250/2500/5000 dither fixtures. Reject a note-box pattern with the exact Theme property pointer. Recheck generated evidence and all existing #466 contrast fixtures before accepting Slice 2.
