# #496 intrinsic density architecture review

**Decision:** accept the [amendment](../../design/issue-496-rotation-invariant-density-amendment-2026-09-29.md) before Slice 1 code publication. The earlier [whole-architecture correction review](issue-496-density-and-note-host-architecture-review-2026-09-29.md) fixed coverage but left the sampling cell ambiguous for non-square rotated tiles. A catalogue's density must describe its own fundamental period and stay rotation-invariant; Layout still owns angle and repeated placement, Scene carries the completed value, and perceptibility may separately inspect a clipped output region. This preserves [Specification 64](../../specification/64-portable-icon-catalogs.md) resource ownership, [Specification 07](../../specification/07-style-and-theme.md) effective paint, and [Specification 08](../../specification/08-scene-and-rendering.md) adapter parity. No new version or compatibility behavior is needed.
