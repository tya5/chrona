# Architecture review — fixed overlay host shortage (#504)

Decision: accept the [fit-contract correction](../../design/issue-504-overlay-fixed-host-fit-correction-2026-09-29.md) against [Spec 33 §13](../../specification/33-intent-oriented-layout.md), [Spec 38](../../specification/38-review-row-composition.md), [Spec 50](../../specification/50-constraint-driven-gantt-surface-quality.md), the [#382 overlay decision](../../design/issue-382-overlay-review-height-theme-correction-2026-09-25.md), and the [R2 design](../../design/issue-504-501-lane-label-search-correction-2026-09-29.md).

The View still fixes lane membership; Theme still supplies the fixed wallboard extent; Layout still measures label demand, allocates rows, records typed shortage, and completes canvas geometry. Scene projects those facts; adapters do not repair fit. The 11 host cannot grow under its declared profile, so natural visible fallback is an intentional exception to host containment. The tests must check that exception explicitly, while preserving containment for growable 02/12. No normative specification change is required because Spec 33 already owns this behavior; no resource identity or public bytes should change.

Release risk: weakening a blanket assertion could hide an unreported spill. Mitigation: identify the overflowing row and require an equal typed deficit, completed-canvas containment, and existing 02/12 strict bounds. The [implementation amendment](../../planning/active/issue-504-overlay-fixed-host-fit-implementation-amendment-2026-09-29.md) will carry the focused and public gates. R2 remains open until CI and #504 acceptance review pass.
