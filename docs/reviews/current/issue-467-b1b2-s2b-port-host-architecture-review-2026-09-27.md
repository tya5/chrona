# Architecture Review — S2b port-host bounds (#467, #494)

**Reviewed:** [port-host correction](../../design/issue-467-b1b2-s2b-port-host-bounds-correction-2026-09-27.md), [S2 design](../../design/issue-467-b1b2-facet-count-asof-design-correction-2026-09-27.md), Specifications [38](../../specification/38-review-row-composition.md), [46](../../specification/46-completed-scene-paint.md), [50](../../specification/50-constraint-driven-gantt-surface-quality.md), the #466 semantic mark/annotation-port correction, existing `MarkPlacement` and `symbol_parts()`, and S2a `LaneMarkFacet` validation. **Public base:** `6543b1c51233d1fa279b485d769d60fe961d06cc`. **Decision:** accept the two-bounds invariant before S2b product code.

The correction restores the ownership distinction already present in Layout: the semantic mark slot owns connection ports, while emitted parts own exact primitive and visible-stroke geometry. A source-keyed owning facet holds both facts atomically, avoiding a parallel provenance table or phantom primitive. First-facet ownership is deterministic across glyph parts and attached points, and repeated source objects retain projection-instance identity. This is an internal data-model refinement, not a change to Project, View, Theme, Scene or adapter semantics. Layout remains responsible for completed ports, collision geometry and later routes; Scene only projects the completed result. It is consistent with #466's explicit boundary-port anchor and does not weaken required-label obstacle or #494 no-crossing rules.

The main risk is accidentally using host bounds as a collision footprint or expanding primitive bounds to contain the ports. Both are forbidden and covered by focused fixtures. The corrected validator must still reject any port outside its completed host and duplicate port identity. No generated public bytes should change while lane mode is guarded. Publish a small S2a contract correction, then S2b mapper/preflight, each with focused tests and review; return to design if a mark has no completed host bounds.
