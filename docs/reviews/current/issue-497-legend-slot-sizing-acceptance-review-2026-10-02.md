## Architecture and release conclusion

Layout owns the legend's size, its shrink and its warning; View and Domain supply the same entries to measurement and drawing; Scene gained no field; the gate reads committed Scene JSON only. Preset layouts, Themes, schemas and corpus data are untouched, so there is no schema equivalence to run and no preset conflict with #718. All four rows are `met`; there is no narrowed or deferred row and so no successor issue.

Disclosures:

- **#499 is left alone.** Its relation-key zero bounds are Scene serialization, its aspect rule is swatch geometry and its Editorial fill is a preset (#718's area); none is a mechanism this work uses, and the gate reads text and diagnostics, not swatch bounds. The new `swatch_extent` function is its natural home for the aspect rule. Decision recorded on #497.
- **Scope of the container bound.** It applies to `content`-sized slots of a source whose composer shrinks and reports (a closed set, today `legend`), in a column or row container. A `content` legend placed in a grid or flow, or declared `visible-overflow` (as the packaged `executive-light` footer legend is), is not bounded and keeps the existing `W_LAYOUT_VISIBLE_OVERFLOW` behaviour. Other composers that ellipsize (table cells, detail panels) are outside this work and have their own reports.
- **Inline legend block size is unchanged.** The inline size of an inline legend is now the line of entries, but its block size stays the conservative stack of every run, because the number of wrapped rows depends on the inline size the slot is given. An early version that changed it moved four unrelated slides and was reverted; recorded in the work record.
- **Numeric spacing.** The measured label width does not pass the numeric-spacing mode that drawing passes. It can differ only where a Theme declares tabular numerals for the legend, and then the result is an ellipsis that the new diagnostic reports, never a silent one.
- **Rendered output was read** from `resvg` PNGs of the three regenerated slides; no browser or other renderer was compared.

Exact review-bearing-main three-OS CI and newest-Python materializer run must pass before closing #497; record that run in the issue closing comment.
