# Architecture Review — S2b closed lane projection (#467, #494)

**Reviewed:** [design plan](../../planning/active/issue-467-b1b2-s2b-closure-reconciliation-design-plan-2026-09-27.md), [selected correction](../../design/issue-467-b1b2-s2b-closure-reconciliation-correction-2026-09-27.md), Specs [38](../../specification/38-review-row-composition.md), [46](../../specification/46-completed-scene-paint.md), [50](../../specification/50-constraint-driven-gantt-surface-quality.md), #466 obstacle phase ordering, #486 attached-point semantics, #494 route gate, #498 preset-default decision, and current public Layout/Scene code at `c05fb917ec3e307a2c66853167eab0571bf8458a`. **Decision:** accept the correction as the S2b/B2 authority, subject to the implementation-plan gates below. No product implementation is accepted by this review.

| Architecture connection | Review finding |
| --- | --- |
| Project, Schedule, Actual and View | Scheduled dates and selected `as_of` remain upstream facts. View v0.27 selects lane mode, track relation, labelVisual and attached host; Layout may not infer them from rendered coordinates. Repeated source objects require a distinct projection instance. |
| Theme, fonts and icon catalog | Theme resolves glyph/icon paint and typography before lane preflight. The immutable plan retains those identities and the completed geometry/paint payload; B2 cannot query a changed Theme or load an asset again. |
| Layout allocation and composition | A single frame-parameterized mark composer removes the absolute/local coordinate mismatch. One preflight owns candidate, label and lane closure. Final composition translates once and verifies seed/final identity; it cannot reallocate. The facet overlay rule is narrower than the draft all-comparison exemption. |
| Scene and adapters | Scene v0.6 carries completed primitives, paint, lane/member provenance and mark-band anchor. It does not choose label rungs, compute symbol parts, or classify collisions. Adapters serialize exactly; the Scene audit reads actual completed footprints. |
| #466 and #494 routes | Required lane labels become obstacles before routing. Completed semantic ports use their declared host slot. B3 remains responsible for no-crossing and cause-specific suppression evidence; no route exemption is implied by a lane overlay. |
| #467 and #498 release | The owner withdrew numerical 12/14 targets. Pairwise non-redundancy and a reported overlap lower bound are release checks, not allocator shortcuts. Packaged default and Editorial reference migration occur only after B2/B3 gates. |

The principal implementation risks are automatic byte drift from extracting formulas, lossy facet copying (especially icon and glyph payload), incomplete expected marks, and duplicate or omitted attached members. Each has a focused fixture and a batched public-materializer check in the successor implementation plan. Unsupported point folding is an explicit failure, not a silent conversion. No new public View syntax is selected; the optional lane-only Scene fields already exist. If a required glyph/progress/label projection cannot be closed without Scene-side policy, the slice returns to design. The issue remains open; every literal #467/#494 acceptance row in the design plan is deferred until rendered release evidence exists.
