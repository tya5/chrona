# Architecture Review — Atomic lane label visuals (#467, #494)

**Reviewed:** [label-visual correction](../../design/issue-467-b1b2-lane-label-visual-correction-2026-09-27.md), [design plan](../../planning/active/issue-467-b1b2-lane-label-visual-design-plan-2026-09-27.md), Specs [38](../../specification/38-review-row-composition.md), [46](../../specification/46-completed-scene-paint.md), [50](../../specification/50-constraint-driven-gantt-surface-quality.md), existing View visual target and `resolve_label_visual_advances`/`resolve_text_visual_requests`, S2 mark facets, #466 phase-one text/route obstacle policy, #350 icon catalog and #498 packaged defaults. **Public base:** `7c054b5aaa1e51c9543abcdc53dca4ba5319fc1c`. **Decision:** accept the atomic label-bundle model for implementation planning.

The existing scalar lane-label width omits View text visuals; later icon placement cannot repair a collision decision made without them. Treating them as mark facets would mix mark and required-label ownership, while copying automatic coordinates would violate selected lane geometry. The selected finite variant model reuses Layout's existing visual advance/resource closure but moves text and icon together through one immutable preflight plan. Component footprints avoid counting empty space inside an aggregate width as a collision and allow the owner-required Scene no-redundant-lane proof. Label components enter the phase-one shared obstacle set before routes; Scene and adapters never reposition them. Mark-icon aggregation remains a separate projection problem with reusable emission facts, not shared collision ownership.

The principal risk is altering automatic-mode text-visual fitting while extracting shared measurement. Keep that path byte-characterized and use the new candidate-variant path only for lanes. A missing/mismatched normalized icon or text measurement must fail before allocation. A selected rung that fits text but not its icon is invalid, never a partial placement. No public schema syntax or compatibility shim is needed; View intent is already closed. The implementation plan must separate reusable measurement, finite variant/allocator model, B2 projection and generated evidence, each reviewable/publishable with focused tests.
