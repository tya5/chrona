## Architecture and release conclusion

The kind is a Project fact reaching Layout through the View's existing `projectAnnotation` link; the View gained no property. The Theme owns the vocabulary and appearance (`annotationKinds`, the roles, `tiltDegrees`), Layout reads Theme strings and geometry only and completes every rectangle, path and text origin, Scene carries completed primitives and the kind colour as paint, and adapters serialise. Every addition is optional and its absence is today's output (every committed slide regenerates byte-identical in each PR; that is no-change evidence only, not a quality bar). The per-kind colour reuses the Theme colour-binding grammar, the stamp reuses the catalogue glyph path, the tilt reuses the `Symbol` path and the text-rotation pivot, and the header text is judged against its real ground at Theme resolution and in the Scene gate.

Disclosures:

- **Evidence fidelity.** The Title Card slide uses English labels (`Warning`, `gate review`) because the Latin bundle carries no kanji metrics in these Contexts, so `警告`/`報告` and the seal glyphs `危`/`記` beyond the synthetic seal test are not image-verified in a drawn corpus slide (the seal glyphs are drawn as paths in the synthetic test). The Marquee look beyond tilt (newsprint ink, clipping artwork, a rail with dotted leaders) is not on the slide: newsprint ink hits a pre-existing limit ([#950](https://github.com/tya5/chrona/issues/950): the Theme-resolution check of note ink compares it with the canvas surface), the clipping is [#848](https://github.com/tya5/chrona/issues/848), and a leader connector on the HALCYON board falls back to the visible-overflow placement for the Ground-station note with or without a tilt (existing #449 behaviour), so the leader behaviour is proved on synthetic fixtures. Assembling complete Title Card, Marquee, Yuya and Target B presets belongs with the packaged presets and parts and the target gap map (#718, #453, [#883](https://github.com/tya5/chrona/issues/883)).
- **Adapters.** Typst never draws a tilted note: it rejects the `Symbol` box, as it already rejects a balloon, so no unverified Typst pivot was shipped; SVG, PNG and TikZ draw it.
- **Authoring consequences.** A stamp glyph with stroked parts needs a rich visual profile (its line cap and join are required), like any catalogue glyph. A bar or accent on a balloon or image outline is `E_LAYOUT_ANNOTATION_KIND_FRAME_OUTLINE`. A label visual on a tilted note is `E_LAYOUT_ANNOTATION_TILT_VISUAL`. The stacked lines of one tilted note are exempt from the text-intersection checks (their axis-aligned bounds overlap, the lines do not).
- **Gate maintenance.** The schema-equivalence expected-delta entries of the Theme nodes several slices touch go stale when the node moves on; A584-3 repaired the older #584 entries to the base state (the precedent of #583 for `periods`).

Exact review-bearing-main three-OS CI and newest-Python materializer run must pass before closing #584; record that run in the issue closing comment.
