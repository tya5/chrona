# #496 Rect pattern admission architecture review

**Decision:** Accept the [correction](../../design/issue-496-rect-pattern-admission-correction-2026-09-29.md) and Specification 07 update. The current Scene builder emits Rect for missing-actual, network-node, progress-fill, summary-bar, annotation-highlight-box, axis-band-decoration(2), and the three chips. Planned/actual/snapshot/scenario can emit Symbol; milestone swatches are Symbol; balloon callout/arrow boxes are Symbol. Scene's PatternGeometry is Rect-only, so retaining those mixed roles would violate Theme admission and the Layout→Scene→adapter boundary. This correction keeps the public Theme v0.13 contract truthful, leaves #464 glyphs and #466 annotation geometry intact, and requires no version change. Future Symbol patterns require an explicit successor design, not a local conditional.
