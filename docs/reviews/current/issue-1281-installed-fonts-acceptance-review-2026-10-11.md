# Acceptance review — installed fonts on every render path (#1281)

Implementation: [#1337](https://github.com/tya5/chrona/pull/1337) (merge `7e4743b14`), checked against `origin/main` `f890cea6c`. A Theme `fontFamily` is an ordered list; per role the first declared or installed family wins, else the packaged Noto Sans; a missing glyph takes the next face that has it; installed faces are found by scanning the standard directories (no fontconfig requirement); one resolver (`fonts/resolution.py`) serves the draft closure and `render-review`; `E_FONT_SYSTEM_IMMUTABLE` is gone. Plan and decision table: [Status comment](https://github.com/tya5/chrona/issues/1281).
