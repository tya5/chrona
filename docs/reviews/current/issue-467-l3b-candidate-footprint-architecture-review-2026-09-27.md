# Architecture Review — Atomic Lane Candidate Footprints (#467)

**Decision:** approve the [candidate-footprint correction](../../design/issue-467-l3b-candidate-footprint-correction-2026-09-27.md) for a B1/B2 implementation-plan amendment, not for public lane activation. **Plan:** [design plan](../../planning/active/issue-467-l3b-candidate-footprint-design-plan-2026-09-27.md). **Base:** published L3b preflight/route design at `21b17c44`; this review closes a mapping gap discovered while implementing from that design.

| Whole-architecture boundary | Finding |
| --- | --- |
| Project/Schedule/Actual and #486 | The authored `attachesTo` and scheduled dates remain semantic facts. Projection selects the host and attached point and keeps each source identity. Layout alone pins them to a generated lane and measures the intended overlap; neither Project nor View assigns a track. Frozen baseline and actual observations are unchanged. |
| View/Review projection and Specification 38 | `rows.mode: lanes` and required label intent remain the existing v0.27 contract. A Review row is an atomic candidate bundle input, not a final lane. Comparison members add mark facets without duplicate item names; attached points retain independent visible facts. The living Specification 38 now states that invariant. |
| Theme/FontMetrics and #480/#487 | One measured title/date/delta string per required member, the same font-asset identity, Theme mark-role geometry, table text line block and measured table-column path are used before content-height resolution. No adapter-side width estimate or hidden second label policy is introduced. |
| Layout #467/#466/#481 and Specification 50 | The allocator admits or rejects the whole bundle against one obstacle index; final composition translates the accepted local frame once. Natural lane height and full group-band extent are reserved before routes. Required member text precedes routes and cannot be exempted to regain a path. Existing relation quality policy is untouched. |
| Scene/SVG and existing `automatic`/`explicit` | Lane mode has a separate shared mark-level realization; the legacy member-index track helper is not changed for existing modes. Scene receives completed per-member mark/text identity and does not repair a lane. Public automatic Scene/SVG byte characterization remains a release gate. |

The selected atomic bundle rejects flattening attached text, post-allocation child placement, comparison-as-independent-candidate, and centering a mark without its stagger text frame. These would respectively lose source identity, invalidate collision/height evidence, inflate lanes, or let required text escape its row. The exact frame translation and max row-size formula are deterministic for both `pack` and `fill` and permit direct containment tests. The design has no unresolved product choice for B1/B2; if an actual resource exposes a mark class unavailable before preflight or the 02 threshold fails, implementation pauses for another design review rather than patching Scene.
