# Architecture review — #504/#501 Layout correction

The [correction](../../design/issue-504-501-layout-background-correction-2026-09-29.md) restores the intended separation in the [original review](issue-504-501-readable-default-architecture-review-2026-09-29.md). View still declares row mode and label intent; Theme declares paint and order; Layout owns measured demand, row allocation, bounded placement, suppression evidence and permitted background intersections. Scene projects completed shapes/text, and adapters never decide overlap or retry labels. Specs 38 and 50 receive the normative clarifications; no schema or compatibility promise changes.

The original plan's R2/R3 implementations pause at this correction. A generic translucent-overlap exception would weaken #481's compound-fill guard; the accepted exception is only later-painted `calendarClosed` over row/group/header bands. A fill-only resource change currently fails on the starter and cannot be accepted. The correction is architecturally consistent once the focused negative overlap tests, positive starter SVG/PNG paint checks, and lane demand/suppression evidence pass. Resume R2/R3 only after this document and the amended plan are public.
