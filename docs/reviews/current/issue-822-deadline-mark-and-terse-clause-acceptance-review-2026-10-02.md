## Architecture and release conclusion

`deadline` stays a promise (Q-SCHED-2): the scheduler never reads it, drawing it moves no placement, verdict or analysis, and a terse clause only stores the date. Lateness is decided once in Core and carried as a verdict, so Layout never subtracts dates; Layout anchors to the completed planned mark (so lane and automatic rows need no special case), Scene carries completed `Path` primitives of one registered semantic, and adapters serialise them. The View member and the Theme property are optional and in place; omitting them is today's output (a View without `deadlines` renders byte-identical, with and without the role declared; every committed example is unchanged). The terse change is strictly additive and `chrona.terse` still imports only `core`.

Disclosures:

- **No packaged preset has the role.** A View that shows deadlines on a bundled preset gets `E_THEME_ROLE_REQUIRED` until the preset or the author's Theme declares `deadline-mark`; the packaged `warning` brown scores 1.7:1 on the blue bar and would fail the 3:1 gate, so the preset needs another ink ([#946](https://github.com/tya5/chrona/issues/946), preset lane #718).
- **Obstacle scope.** The paths are `rule` obstacles: annotation candidates avoid them; member labels and routes may cross them, as they may cross the as-of rule (Specification 50 says so).
- **Terse warning position.** `W_DEADLINE` carries no source position for a terse plan (the warnings channel has no `sourceRange`); an impossible terse date is caught by the lexer, so `E_SCHEMA` is unreachable ([#946](https://github.com/tya5/chrona/issues/946)).
- **Stale shared entries.** Run against a base that already contains them, the S0 gate reports the `#584` expected-delta entries for `annotationKinds` and the Theme `values` as "does not apply"; the entries of this issue pass. The PR checks run L2 and L3 only and passed.
- **Local-only failure, not a product defect:** the generated `diagnostic-inventory` report differs in a working tree until the derived sync regenerates it.
