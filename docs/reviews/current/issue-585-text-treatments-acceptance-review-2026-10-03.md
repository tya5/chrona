## Architecture and release conclusion

Theme declares how a role's text is set; Layout owns the measured (compressed) width, the vertical segmentation and the tag column; Scene carries a completed factor and ordinary completed Text; adapters serialise and decide nothing. A scale enters measurement once, through the metric Layout already selects per role, so about twenty measuring sites needed no edit and the honesty sweep proves none ignores it (the two records that bypass a role carry the factor and are covered by tests). Vertical writing uses no new Scene vocabulary: SVG, PNG, PDF, Typst and TikZ draw horizontal and quarter-turn Text today, and resvg's native `writing-mode` was deliberately not used because its extents come from shaping Layout cannot know before painting. Both properties are optional under Specification 56 section 3.2 and their absence is today's output (byte-identity tests; every committed slide regenerates unchanged, which is no-change evidence only, not a quality bar).

Disclosures:

- **Design correction.** The record first rejected vertical tags on lane rows; every committed View and the packaged bundle use lane rows, so the rule was withdrawn before code ([PR #960](https://github.com/tya5/chrona/pull/960)).
- **Gate maintenance.** The schema-equivalence expected deltas for the Theme `values/additionalProperties/allOf` node went stale against a base that already carried the #584 chain; I585-1 refreshed those four entries to the base state and I585-2 added entries for the token-type enum and union. A CLI golden fixture that lists the token types gained `writingMode`.
- **Adapters.** Typst source for a compressed or rotated text is not compile-verified (the existing `place(left:, top:)` form is rejected by Typst 0.15; the `scale` and `rotate` fragments were measured). TikZ rejects compression. PDF is not image-verified. Tracked in [#982](https://github.com/tya5/chrona/issues/982).
- **Perceptibility.** The tags tile their column without overlap, so slot escape, occlusion and text-intersection checks judge each segment; a collision of two segments is caught (tested). Group-header contrast is gated by #884 / #964.
- **Authoring consequences.** `horizontalScale` outside 0.5 to 1 is `E_THEME_TEXT_SCALE_RANGE`; `writingMode` on a role other than `groupHeader` is `E_THEME_ROLE_PROPERTY_UNSUPPORTED`; a scale and a vertical mode on one role is `E_THEME_TEXT_TREATMENT_CONFLICT`. A vertical label replaces the horizontal header row (one label per group); a second horizontal row beside it, as the Yuya mock shows, is not part of this work.
