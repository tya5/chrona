# Architecture Review — S2b icon emission closure (#467, #494)

**Reviewed:** [icon correction](../../design/issue-467-b1b2-s2b-icon-emission-closure-correction-2026-09-27.md), [S2b design plan](../../planning/active/issue-467-b1b2-s2b-icon-projection-design-plan-2026-09-27.md), [S2 facet design](../../design/issue-467-b1b2-facet-count-asof-design-correction-2026-09-27.md), [S1 Layout geometry ownership](../../design/issue-467-l3b-b1b-2-stroke-aware-footprint-correction-2026-09-27.md), Specs [38](../../specification/38-review-row-composition.md), [46](../../specification/46-completed-scene-paint.md), [50](../../specification/50-constraint-driven-gantt-surface-quality.md), current `IconPlacement`/`IconPathPlacement`, Scene v0.6 builder/model and icon catalog normalization. **Public base:** `10cc1fc9bd0c6a6119bc400294d811dce1a970bd`. **Decision:** accepted for an implementation-plan amendment; S2b icon code remains paused until it is published.

The selected group contract keeps the needed facts in the same immutable source-keyed facet closure used for collision and B2 projection, without a drifting side table or ID decoding. Individual path facets retain exact Layout geometry/footprints; a typed group key makes the existing one-primitive Scene ICON emission deterministic. The allocator remains renderer-neutral and oblivious to path paint; Scene paint resolution receives already-completed path intent and stroke width, not a request to transform or rescale. Raster bytes and asset identity remain a closed resource fact, not a B2 reload. This respects Project/View selection, Theme/icon appearance, Layout geometry, Scene projection and adapter serialization boundaries. No compatibility behavior or public policy is added.

Risk: duplicating common metadata across vector path facets could drift. The group validator must require exact equality, contiguous indices and one emitted icon per group. A placed icon viewport is not a substitute for each path's collision footprint; both are checked. Generated automatic artifacts remain byte-stable because the public lane guard is closed. #467's rule-based Scene-footprint audit and #494 routes remain later gates; this correction does not claim either. Publish type/validator tests, then mapper/preflight, then B2 Scene grouping as separate reviewable units.
