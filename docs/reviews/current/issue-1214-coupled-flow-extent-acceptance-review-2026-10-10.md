# Acceptance review — least fitting block extent for aspect-coupled flows (#1214)

Implementation: [#1325](https://github.com/tya5/chrona/pull/1325) (merge `aa30dd96`), checked against `origin/main` `289444de`. `resolve_content_block_extent` assumed that "every required slot is allocated its demand" is monotone in the block extent. It is, except when an inline `aspectRatio` derives a flow's inline size from its block size: a taller extent widens the flow, its items wrap into fewer lines and a slot shrinks. For a profile that has such a coupling (`_block_extent_feeds_inline`) the resolver now selects the first integral extent from the requested minimum up to the already verified deficit extent whose complete native manifest fits (`_first_fitting_extent`); other profiles keep the deficit probe and bisection. Rule: Specification 33 section 13.1. Plan: [Status comment](https://github.com/tya5/chrona/issues/1214).
