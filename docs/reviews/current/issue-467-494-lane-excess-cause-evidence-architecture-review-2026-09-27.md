# Architecture Review — Excess-lane cause evidence (#467, #494)

**Reviewed:** [evidence amendment](../../design/issue-467-494-lane-excess-cause-evidence-amendment-2026-09-27.md), [owner-amendment correction](../../design/issue-467-494-lane-count-acceptance-correction-2026-09-27.md), Specs [38](../../specification/38-review-row-composition.md), [46](../../specification/46-completed-scene-paint.md), [50](../../specification/50-constraint-driven-gantt-surface-quality.md), the selected #467 design, #466 obstacle phase order, and the current allocator/result types. **Public base:** `e6d50c3c9d12facba916727a041dea7fbe2de526`. **Decision:** accept the per-group and source-keyed trace model for B2 planning.

The source issue's ten-lane estimate is per-group; a global ordinal would misclassify group isolation and fail the owner's allowed-cause taxonomy. The corrected per-group excess inventory is conservative even when one group uses fewer than its estimate. Source-keyed rejected attempts provide direct measured witnesses, retain deterministic ordering and avoid rerunning allocation from a possibly changed frame. The Layout boundary is maintained: Project defines source items and dates, View selects them, Theme resolves metrics, Layout measures/rejects/places, Scene projects completed geometry, and adapters serialize. Neither acceptance prose nor Scene code substitutes for missing Layout evidence.

There is no approved hard chain-placement prohibition in the current allocator, only predecessor preference. Therefore the review rejects attributing an extra lane to "chain rule" without a future typed enforced rule/relation witness. Likewise a canvas-only refusal is not a mark/label collision. Both become explicit design-return conditions, not fallback classifications. S2b facet mapping does not depend on these result fields; B2 does. No public schema/resource migration is implied. The prior 14-lane gate, named chain, required text, route cause and public materializer obligations remain unchanged.

**Risk and follow-up:** Recording every rejection can increase internal result size; it is bounded by finite candidates × prior lanes × finite ladder and need not appear in public Scene. Focused tests must cover mixed blockers, multiple failed rungs, per-group excess when global order crosses a group boundary, and no false `chain-rule` cause. Publish an implementation-plan amendment before adding allocator code.
