## Architectural review

Font closure belongs to Context/materialization; Layout consumes resolved metrics;
Scene remains a completed-placement/paint projection; output adapters consume only
declared static font files. Layout's token interface is validated before geometry
allocation and does not introduce defaults or a Theme-to-Scene policy edge.
The static-face correction was published before its implementation to preserve the
metric-to-raster identity invariant.
