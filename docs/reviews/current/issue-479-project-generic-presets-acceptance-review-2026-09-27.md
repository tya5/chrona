## Architecture and release conclusion

The View/Projection owns derived ordering, field domains, and the declared name placement; Theme/Scheme owns categorical colours; the preset package chooses the optional detail profile and visual-profile preference; Layout and Scene retain their existing geometry/projection responsibilities. Explicit CLI overrides remain authoritative. The seven criteria are met on the published base, so #479 is ready to close. The View-version order changed from the original expected v0.27: #467 lanes had not landed, so this slice used v0.26; #467 must now target the next version, as recorded in the slice review. This is a sequencing adjustment, not an unreviewed change of #479 semantics.
