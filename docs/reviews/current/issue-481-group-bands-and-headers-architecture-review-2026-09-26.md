## Reviewed ambiguities and resolutions

1. **Guaranteed stripe-on-top vs. Theme-authored order.** The design does not force stripes above bands structurally (e.g. by ignoring Theme `backgroundPaintOrder` for these two roles); it only fixes the *emission* order so that the existing tie (which every shipped preset currently has) resolves in the stripe's favor. An author who explicitly wants the opposite still controls it via `backgroundPaintOrder`, preserving that token's existing promise. This is the smaller contract and does not special-case two roles inside a token that is meant to be general.
2. **Header-band gating could have folded into `content_bounds` alone, removing the independent `groupHeaderBand` shape entirely.** Rejected: `groupHeaderBand` is a distinct, already-published semantic (Specification 49 §3, registry entry `groupHeader`/purpose `group-header-band`) used for the header-only technique (`groups: none`), which must remain fully independent of body-band selection. Keeping two shapes with a shared selection predicate (`banded`) is the smallest change that preserves that independent capability while removing the alternate-mode ambiguity.
3. **Silent `text`-role fallback for Themes missing `groupHeader`.** Rejected in the design itself (AGENTS.md's closed-Theme-contract policy; Specification 49 §5.1's required-binding failure rule). The fix is symmetric with how every other required Theme role already works: a missing role is `E_THEME_ROLE_REQUIRED`, resolved by declaring it, not inferred.
4. **Scope of the nine Theme-file edits.** These are not incidental — they are required for Contract 3 to ship without breaking `elevated-light`/`executive-light` and the seven example Themes that reuse those bundles' pattern. The evidence bounds the list precisely (a full focused-test run against the prototype); it is not open-ended.

## Risks and gates

- **Byte batch for Contract 2:** the `content_bounds` header-inclusion moves every painted `groupBand`'s top edge by `timeline.groupHeader.blockSize` wherever a preset bands a headered group. The slice review must attribute every changed group-band `Rect` to this contract and confirm no row or mark geometry moved (only the background shape).
- **Byte batch for Contract 3:** weight/size changes on `group-header:*` text for `control-room-dark`/`mission-light`/`print-mono`; new declared-role text paint for `elevated-light`/`executive-light`. The slice review must confirm no other primitive changed and that the two presets' visual intent (group cards, not bold headers) is preserved by the chosen `weight.regular` declaration.
- **Test-suite blast radius:** the prototype's 76 failures are all attributable to the nine Theme files; the implementation slice must fix all nine in the same commit as the `typography_role` switch (not a follow-up), or CI breaks between commits.

No unresolved user choice remains.
