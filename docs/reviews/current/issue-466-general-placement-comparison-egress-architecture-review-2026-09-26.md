# Architecture Review — Comparison-Host Egress (#466)

**Reviewed:** [correction](../../design/issue-466-general-placement-comparison-egress-correction-2026-09-26.md) against Specifications 06, 08, 33, 38, 44 and 50, explicit-row instance identity, comparison marks, #449 fallback and #467 lane packing.

The semantic relation endpoint remains the Project-defined date and View-resolved instance. Moving that date to a scenario sibling's finish would falsify it; ignoring every mark in its row would make obstacle closure meaningless. A finite same-object/same-row host corridor preserves both temporal truth and strict obstacle checking after egress. The exemption is typed and segment-scoped, so an unrelated mark or label remains blocking. Layout alone constructs and records the corridor; Scene and SVG do not infer comparison membership. Accepted for O2, with neutral tests for overlapping sibling, unrelated mark, duplicate object in another row, point glyph, corridor identity and deterministic order. Public HALCYON 04 relation and generated bytes must be reviewed before acceptance.
