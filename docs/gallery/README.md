# Public Example Gallery

This gallery indexes rendered evidence from the declared regression corpus.  It
does not own a renderer, a source closure, or hand-authored SVG.

- Controller Z / executive: actual-vs-plan executive review and label fitting.
- ASTER SSD / overview: plan-only, calendar-aware semiconductor schedule.
- HALCYON / programme-board: dense programme and typed summary surface.
- HALCYON / dependency-network: dependency-network geometry and routing.

Each entry is validated by `example-gallery.yaml` against a corpus manifest.
Reproduce an artifact through `tools/materialize_example.py` using the linked
manifest and slide identity.
