## chrona font

## chrona font import

import one static, TTC, or instantiated variable font

`chrona font import --axis --family --index --output --weight`

- `source`: local TTF, OTF, or TTC font
- `--family`: declared font family
- `--weight`: declared CSS-like numeric weight
- `--output`: new or existing local font asset directory
- `--index`: TTC face index (default: 0)
- `--axis`: instantiate one variable-font axis; repeatable

## chrona icon-catalog

## chrona icon-catalog import

import a local Iconify JSON collection or declared Theme assets

`chrona icon-catalog import --alias --include --license-spdx --notice-file --output --set --source-version --theme-assets`

- `source`: local Iconify JSON collection (omit with --theme-assets)
- `--theme-assets`: local chrona/theme-asset-source/v0.2 YAML
- `--output`: new v0.3 icon-only or v0.5 Theme asset catalog YAML
- `--license-spdx`: declared upstream SPDX identifier for Iconify input
- `--notice-file`: local complete upstream license notice for Iconify input
- `--set`: canonical set name (defaults to collection prefix)
- `--alias`: additional set alias; repeatable
- `--include`: optional local newline-delimited canonical icon-name manifest
- `--source-version`: explicit upstream collection/package version for catalog provenance

## chrona mcp

serve validate_project, schedule_project, render_draft, list_presets, render_review, compare_baseline, check_command and apply_command to an MCP client; render_review and compare_baseline read a Store inside the workspace; apply_command writes a Store only with --allow-write; needs the optional chrona[mcp] extra

`chrona mcp --allow-write --list-tools --workspace`

- `--workspace`: the only directory the tools may read, and below which a Store may be written (default: the current directory)
- `--allow-write`: let apply_command write the Store (configuration, not approval: it has no approval step); without it the server is read-only and the call is refused with E_MCP_WRITE_DISABLED
- `--list-tools`: print the tool registry as JSON and exit (needs no MCP SDK)

## chrona render

draw a slide from a Project: SVG, PNG, PDF, Typst or TikZ by the output suffix. A draft for review, not reproducible evidence

`chrona render --actual --detail --emit-scene --font-metrics --format --icon-catalog --layout --locale --output --preset --scheme --summary --system-fonts --theme --typesetter-adapter-grammar --typesetter-engine --typesetter-version --view --viewport --visual-profile -o`

- `project`: Draft Project YAML path, or a terse .chrona plan
- `--preset`: Presentation preset YAML path, or a builtin catalogue id (see `chrona preset list`); omit it to use bundled chrona-default-draft; explicit resource flags override its members
- `--view`: View YAML path
- `--theme`: Theme YAML path
- `--scheme`: Color Scheme YAML path
- `--layout`: Layout Profile YAML path
- `--actual`: Actual Set YAML path
- `--summary`: Summary Profile YAML path
- `--detail`: Review Detail Profile YAML path
- `--icon-catalog`: explicit local icon catalog YAML path; repeatable
- `--font-metrics`: declared-metrics-v3 YAML descriptor; paths resolve beside it
- `--system-fonts`: require the Theme's exact installed face through fontconfig (installed fonts are always usable; this refuses a fallback)
- `--viewport`: Draft viewport WIDTHxHEIGHT or WIDTHxauto (default: 1600xauto)
- `--locale`: render locale: en-US or ja-JP (default: en-US)
- `--format`: output target (default: infer from .svg/.png/.pdf/.typ/.tex; SVG without a suffix)
- `--visual-profile`: exact visual capability profile (default: the preset's preferred profile, else baseline)
- `--typesetter-engine`: required with --format typst or tikz
- `--typesetter-version`: required exact engine version with --format typst or tikz
- `--typesetter-adapter-grammar`: required adapter grammar with --format typst or tikz
- `--output, -o`: where to write the result; an existing file is not replaced
- `--emit-scene`: write a schema-validated inspection Scene JSON without replacing an existing file

## chrona render-review

draw a slide from a saved render context; the same inputs always give the same slide

`chrona render-review --allow-missing-content-identity --context-reference --emit-scene --format --output --reject-unused-closure-inputs --snapshot-root --store-config --store-identity -o`

- `--context-reference`: saved render context reference YAML
- `--store-config`: Store config YAML (for example .chrona/store.yaml); its integrity setting applies and replaces --snapshot-root/--store-identity
- `--snapshot-root`: local snapshot adapter root (required without --store-config)
- `--store-identity`: expected local snapshot store identity (required without --store-config)
- `--allow-missing-content-identity`: accept references without an exact content identity (explicit opt-out)
- `--reject-unused-closure-inputs`: reject a render whose context lists inputs the render never reads
- `--format`: assert the Context target format
- `--output, -o`: where to write the result; an existing file is not replaced
- `--emit-scene`: write a schema-validated inspection Scene JSON without replacing an existing file
