# Design correction — finite lane stagger envelope (#504)

The [R2a correction](issue-504-501-lane-label-search-correction-2026-09-29.md) made inline interval concurrency the preflight row minimum. An implementation probe with `fill` and full-band search still suppressed the AIT lane's last name: labels whose inline intervals appear independently placeable compete with completed marks and previously placed label/route obstacles in the same block band. An interval-only lower bound is not a sufficient host-allocation promise.

Layout retains the interval calculation but takes the maximum of it and a finite conservative envelope: one measured block level plus the measured placement clearance per selected lane member label, above the completed subtrack mark extent. This is a row minimum, not a prescribed final label position or a lane-membership rule. `fill` distributes any remaining timeline block after these minima. The final solver still chooses sides and full-row contact positions against actual obstacles; a geometrically impossible inline candidate remains an `obstruction`, not a capacity claim. Theme metrics, visual advances, chip padding, and wrap remain shared between preflight and final placement. No View, Scene, adapter, or public schema changes follow from the envelope.

The conservative bound is intentionally allowed to allocate more block than interval concurrency alone. It avoids a profile fixed-point search and cannot silently shrink when labels later collide with marks. Its bounded cost is linear in the finite labels in each lane. The R2 stop gate remains: context 02 must have zero suppressed names after the final 02/11/12 batch; otherwise a further design review is required.
