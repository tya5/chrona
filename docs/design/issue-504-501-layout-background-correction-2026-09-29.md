# Design correction — lane label growth and calendar overlay (#504, #501)

Amends the [selected design](issue-504-501-readable-default-design-2026-09-29.md) after probing the published `c1031237` base. `rowDistribution: fill` alone changes 02 from 14 to two suppressed names, but fixed subtracks remain centred and `place_label` searches only one label-height tangentially; spare row height is not necessarily available to names. The #501 faint `calendarClosed` fill intersects the starter's translucent `rowBand`, and Layout currently raises `E_LAYOUT_BACKGROUND_OVERLAP` before Scene output. Neither issue can be solved by a Theme-only or YAML-only workaround.

Layout will measure each lane's label demand before final row allocation, using closed font metrics, title/attached text widths and the shared temporal scale to find concurrently overlapping end-side candidate intervals. A lane's minimum includes its mark-subtrack extent plus the finite vertical label levels they require. `fill` distributes remaining plot height after those minima. For lane labels only, the deterministic closest-first side search may traverse the full legal row band, with bounds and the measured maximum useful extent as finite limits; other labels retain their current search. A suppressed lane-name decision records the lane ID, final row extent, maximum useful extent and limiting reason. No suppression is accepted merely because the old one-line tangent search ran out. Layout never changes View membership or delegates a retry to Scene.

Calendar closure is an intentional semantic overlay. Each `calendarClosed` fill may overlap a row/group/header band when their Theme paint orders are distinct and the calendar layer is later; the completed paint order defines deterministic source-over composition. Closed-day fills must not overlap one another, and other translucent background intersections remain invalid. The default's closure role stays faint and translucent, above row stripes, so row identity remains visible beneath it; the legend uses the same role and paint without reproducing the plot's underlying stripe. An opaque calendar fill or a blanket overlap bypass is not a substitute. Layout validates the narrow role pair and order; Scene carries completed shapes; SVG/PNG serialize or rasterize the same ordered paint.

Migration: the correction changes Layout label search/decision evidence and background validation, not View membership, Theme schema, Scene schema or adapter repair. Tests must show a dense lane gains names when it has spare row height, each remaining suppression's recorded non-growable reason, rejection of unapproved background overlaps, and Scene/SVG/raster paint parity for closed days and legend.
