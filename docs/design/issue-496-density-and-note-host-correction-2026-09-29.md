# #496 correction: sampled pattern coverage and note hosts

**Corrects:** [selected design](issue-496-theme-asset-catalogues-design-2026-09-28.md) and [density precision correction](issue-496-theme-asset-catalogues-design-correction-2026-09-28.md). **Normative authority:** [Specification 64 §8](../specification/64-portable-icon-catalogs.md) and [Specification 07](../specification/07-style-and-theme.md). **Review:** [whole-architecture correction review](../reviews/current/issue-496-density-and-note-host-architecture-review-2026-09-29.md).

The earlier 128×128 rule did not determine coverage at a stroked curve's edge. For density only, each canonical normalized quadratic is expanded to exactly 16 equal-parameter chords; `M`/`L`/`Z` remain straight. Source lines and arcs normalize to round-cap, round-join stroke paths. A sample is covered by a stroke when its Euclidean distance to any chord is **≤ half the stroke width**. Filled circles include their boundary; filled rectangles include left/top and exclude right/bottom. Coverage is the union over primitives and all periodic integer tile translations. Rotate the tile geometry and its repeat lattice clockwise about the tile center; equivalently inverse-rotate a cell center before testing the periodic unrotated geometry. Count each of the fixed 128×128 cell centers once and round the covered fraction to integer basis points half-up. A spatial index may accelerate the same predicate but may not change a result. The emitted Scene/SVG retain the normalized quadratic paths; the fixed chord expansion is only the declared density-measurement rule, not adapter geometry.

The now-published #466 C4 note contract requires an opaque flat representative host ground for required note text and rejects a pattern on that same-source host. Therefore Theme v0.13 does **not** admit `annotation-note-box.pattern`; remove that pair from the #496 allowlist. Other approved pattern pairs and their effective substrate/ink contrast policy stay unchanged. A future patterned-note contract would need to check note text against both substrate and ink across its occupied region before admitting that pair. This correction changes no existing v0.11 Theme or public materializer and does not alter #496's literal issue criteria.
