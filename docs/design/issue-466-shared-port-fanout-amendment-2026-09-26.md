# Design Amendment — Shared-Port Connector Fanout (#466)

**Amends:** [connector topology](issue-466-annotation-connector-topology-correction-2026-09-26.md) and [coincident-port identity](issue-466-coincident-egress-port-amendment-2026-09-26.md).

The controller-z `firmware-slip` leader and a semantic dependency originate at the same completed mark-boundary point `(1063.488, 244.8)`. A bridge route that treats dependency strokes as soft can choose a collinear first leg on that dependency. It then cannot form a transverse bridge; accepting the overlap would make the two semantic paths indistinguishable. A larger A* limit alone does not fix this topology.

When more than one connector leaves one port, Layout enumerates a finite **fanout egress** before ordinary routing. The first candidate is the existing exposed port. Subsequent candidates move from that port by one resolved route clearance along each exterior cardinal direction of the connected mark cluster, in stable end/start/below/above order; an interior or obstacle-crossing stub is rejected. The stub may share only its starting point with an existing route. It may not run collinearly over that route, cross a mark/text/box/rule, or borrow an unrelated port. The exact same-host coincident port aliases are permitted only at the start of the stub. After the stub, strict or bridged routing uses the same shared index and local corridor. The full connector, including the fanout stub, must pass bend/detour quality; the stub and its chosen direction are recorded in the Layout decision. If no fanout works, visible fallback remains explicit and diagnosed.

This is a connector topology rule, not a View annotation preference or Theme paint offset. It applies equally to semantic and annotation routes sharing a port, but O2 may first implement it for annotation leaders using already completed semantic routes; no previously accepted semantic dependency may move merely to accommodate a later leader. Scene projects the completed single Path. Tests must include same-port branching without collinear overlap, unrelated endpoint-port rejection, and controller-z local leader geometry. The O2 public batch and rendered review remain mandatory.
