# Design Correction — Closed lane geometry and projection authority (#467, #494)

**Plan:** [S2b reconciliation design plan](../planning/active/issue-467-b1b2-s2b-closure-reconciliation-design-plan-2026-09-27.md). **Public base:** `c05fb917ec3e307a2c66853167eab0571bf8458a`. This corrects the S2 facet, icon, label-visual, and B2 composition designs where an automatic-row placement was assumed to be a lane-local placement. It does not activate the public lane mode. The current #467 acceptance has no numerical lane-count target; the [rule-based correction](issue-467-494-rule-based-lane-acceptance-correction-2026-09-27.md) remains authoritative.

## Selected geometry and identity contract

Layout owns one shared mark-geometry composition path. Its input includes a typed `MarkBandFrame` containing the inline scale and the mark-band block origin, height, and role offsets; its output is completed, renderer-neutral marks, shapes, ports, symbols, icons, and their visible footprints. The existing automatic and explicit callers pass their present track frames without changing formula order, Decimal conversion, or IDs. The lane mapper passes a frame whose mark-band origin is zero. It must not copy absolute automatic-row geometry or derive a local position by subtracting an unrelated row bound. Every lane-local command, primitive bound, visible footprint, semantic port, port host, icon viewport, and progress clip is within that frame or explicitly declared as a permitted visible overflow. B2 translates the completed local closure once by the final `SceneRow.lane_mark_band_block`; Scene and adapters do not remeasure or reroute it.

Each selected Review row is an atomic candidate. The mapper resolves an attached point's `attached_to` canonical object relation to exactly one selected host projection instance, then carries that instance identity throughout the bundle. Source object ID, View item ID, projection instance ID, countable member ID, and emitted primitive ID remain distinct typed facts. Missing or ambiguous hosts fail before allocation; concatenated strings and source-ref parsing are not identity authority. Repeated source objects in separate rows remain separate instances. A host and its attached points share one candidate and lane, while each countable item retains its own required name and mark/port identity. A point-row policy unsupported by lanes fails explicitly; it is never silently converted to a group-header or predecessor fold. `rows.points: key-row` remains a separately designed row, not an implicit lane.

## Complete facet and label closure

A facet's `primitive_type` has an exhaustive projection payload variant. A plain mark carries its exact shape, corner/end treatment, semantic role, paint order, bounds, commands, ports and host. A Theme glyph part carries its part index/order and completed paint mode/color, not a later Theme lookup. A vector icon retains one path facet per completed path, but one group identity and one Scene ICON emission; its path count, viewport, commands, path paint, scaled stroke, cap/join and asset identity must agree and validate as a whole. A raster icon retains its exact payload. A progress shape carries exact host/clip relation, bounds, paint and order. Unknown or incomplete required variants fail closed. In particular, an ICON facet without its icon projection, a stroke path without finite width, a command outside its completed bounds, and an incomplete icon group are invalid. The semantic port host remains separate from primitive and collision bounds.

The mapper constructs the expected emission set from the selected Review semantics before looking up placements: planned/snapshot, selected Actual or open-Actual cutoff, comparison, point, selected progress, icon mark and required label-visual components. Each expected element is either emitted with its completed payload or has a typed, design-approved intentional-absence reason; a missing placement is never silently skipped. Open Actual is tied to the selected `as_of` date. The completed required-label bundle retains exact title/delta strings, normalized typography, font and Theme identity, measured component bounds, chosen finite rung, and any leading/trailing icon components. B2 projects this bundle; it does not remeasure, copy automatic-row coordinates, or recompute finish delta. A reserved/emitted mismatch fails with `E_LAYOUT_LANE_LABEL_VISUAL_UNAVAILABLE`.

Within one candidate, collision exemptions are explicit symmetric facet-pair relations. They are limited to compound parts of one semantic mark/icon, a progress fill clipped to its declared host, an approved `shared` comparison subtrack, and an attached host relation when the selected View semantics declares it. `stacked` comparison/Actual facets remain obstacles. An overlay cannot exempt required labels or facets in different candidates. Structural copying of a facet must preserve its complete payload and overlay relation, including `icon_projection`; manual partial reconstruction is not allowed.

## One immutable preflight plan and failures

Preflight retains the exact immutable candidates and their source-keyed facets, required-label closure, allocation, selected `as_of`, seed inline frame, measurement/Theme/font/scale identity, and table/group requirements in `SurfaceLanePlan`. B2 accepts that one plan and validates final inline frame and all contract identities before emitting; it must not remap Review input, reallocate, or recompute a label/mark from Theme. A changed cutoff or measurement identity is a plan mismatch; a changed lane-driving inline frame is `E_LAYOUT_LANE_INLINE_UNSTABLE`. The plan's member IDs must bijectively match allocated members; missing/extra projections fail before Scene construction. Runtime lane-specific failures remain typed `E_LAYOUT_LANE_*` diagnostics. No automatic/explicit output bytes change as part of this correction.

## Migration and acceptance boundary

These are internal Layout and lane-only Scene carrier changes; no new View syntax or HALCYON resource migration belongs to S2b. Scene v0.6 already has optional lane provenance and mark-band anchor, which B2 populates only for lanes. The source-keyed Scene footprints still supply the #467 pairwise non-redundancy proof and overlap lower-bound report. #494 route causes and public preset activation remain later gates. The withdrawn 12/14 ceiling and historical ten-lane estimate are not feasibility gates, and no third label row is forced. Verify exact automatic planned/snapshot/Actual/point Scene/SVG bytes, attached and repeated identities, overlay matrix, glyph/icon/progress emission, missing-placement and cutoff failures, then batch public materializers. Any new visual policy found during extraction requires another design correction before code.
