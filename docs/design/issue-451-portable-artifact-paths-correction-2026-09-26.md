# Design Correction — Portable Derived-Artifact Paths (#451)

**Design plan:** `issue-451-portable-artifact-paths-design-plan-2026-09-26.md`  
**Corrects:** the derived-artifact report implementation under
`issue-451-conformance-feedback-design-2026-09-26.md`.

## Finding

`report_stale_artifact` derives a repository-relative `pathlib.Path` correctly
for containment, but interpolates it directly into public report fields.
`Path.__str__` is OS-native, so Windows emits backslashes in the stale code
line, unified-diff headers, and GitHub annotation.  That contradicts #451's
platform-safe, stable report protocol.

## Decision

The repository-relative path has two representations:

```text
relative_path: Path              # local containment and file operations
report_path: relative_path.as_posix()  # every published protocol field
```

`report_path` is the canonical repository identity.  It is used consistently
for the stale headline, both diff labels, and the optional Actions annotation.
No local file operation receives this string, and no absolute path is emitted.

## Invariants

1. Identical stale input has byte-identical human-readable report paths on
   supported operating systems.
2. All outward path occurrences name the same POSIX repository-relative path.
3. Path containment, freshness comparison, generated bytes, refresh argv, and
   exit status are unchanged.
4. The helper remains tool-only and imports no product runtime.
