# Design Correction — Connector Egress Through Comparison Siblings (#466)

**Predecessors:** [shared-obstacle design](issue-466-general-placement-design-2026-09-26.md), [point-port candidates](issue-466-general-placement-point-port-candidate-correction-2026-09-26.md).
**Discovery:** on HALCYON 04, a current planned span's semantic finish lies inside its same-row scenario comparison span. Treating that sibling as an unrelated obstacle suppresses a dependency that was previously visible. The endpoint's temporal x-coordinate cannot be moved to the scenario finish without changing the relation's meaning.

Each relation/annotation connector has one *semantic endpoint port* at the completed mark's declared date. Layout may prepend/append an *endpoint egress corridor* from that port to the nearest boundary of the union of only its same-object, same-Review-row comparison marks (planned, actual, baseline/scenario, missing-actual). The corridor is a completed line segment attached to that endpoint and keeps the semantic port coordinate in the final path. Its collision exemption is limited to precisely those named sibling mark IDs **and only on this initial/terminal corridor**. The route proper begins/ends at the exposed corridor port and queries the full shared inventory; it never receives a row-wide, object-wide or global exemption. A comparison sibling in another authored row is not part of this host set.

The corridor direction is chosen from a finite deterministic set of cardinal exits toward the opposite original endpoint. Candidate order is Manhattan distance from exposed port to the opposite endpoint, then side order end/start/above/below. A candidate is rejected if the corridor intersects any obstacle outside its named host set or if its exposed port cannot lead to a bounded quality route. The source/target candidate product remains finite. Selected corridor geometry, semantic and exposed port IDs, host IDs and candidate count are Layout placement facts. A visible direct fallback retains the original semantic endpoint and records every overlap. The same rule applies to annotation leaders anchored inside their own comparison host cluster.

This is narrower than exempting a whole mark during the whole route. It preserves Project/Review temporal identity and supplies an explicit visualization rule for overlay comparison geometry. Scene projects the completed corridor and route as one connector; no adapter-specific clip or path repair is permitted. No public schema change. Public routes may move; a visible dependency must not be suppressed merely because its semantic endpoint is covered by its own comparison sibling.
