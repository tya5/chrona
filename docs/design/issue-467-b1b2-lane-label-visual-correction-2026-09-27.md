# Design Correction — Atomic measured label-visual bundles in lanes (#467, #494)

**Plan:** [label-visual design plan](../planning/active/issue-467-b1b2-lane-label-visual-design-plan-2026-09-27.md). **Corrects:** the scalar `title_width + delta_width` lane-label contract in the selected [#467 design](issue-467-collision-aware-lane-rows-design-2026-09-26.md) and [S2 facet mapper design](issue-467-b1b2-facet-count-asof-design-correction-2026-09-27.md). **Public base:** `7c054b5aaa1e51c9543abcdc53dca4ba5319fc1c`. `labelVisual` icons are selected View text-visual intents, not mark facets; their automatic-row coordinates cannot be copied to a selected lane rung.

## Selected Layout contract

For each countable root/attached Review item, Layout forms one required **label bundle**: completed title and selected delta text plus resolved leading/trailing `labelVisual` intents. Use the existing `resolve_label_visual_advances` path to obtain icon assets, Theme typography ratio/gap and side in the same source/projection-instance identity as `member-label:<row>:<item>`. Preserve canonical View visual target resolution and existing duplicate/missing-asset diagnostics. Measure the text with the selected font metrics, baseline, lines, typography and font asset identity; reserve both text and icon advances. Do not convert `labelVisual` to a mark facet or count it as a lane member.

The finite label ladder is evaluated as a sequence of **atomic, completed candidate variants**. For each rung, Layout composes lane-local text bounds/baseline and each icon's placed viewport, transformed vector paths or raster viewport, exact visible stroke-aware footprints and complete emission metadata, using the seed inline scale and the same resolved Theme/catalog closure as final output. A variant carries the union of its **component** collision geometries and its natural block extent; it is not reduced to a scalar width or one overconservative rectangle for acceptance. Layout's neutral allocator tests the whole variant against prior marks/required labels, selects one deterministic rung, or opens a lane. It cannot accept text and later drop/move the icon. Selected text/icon placements and collision geometries become immutable lane-plan values; B2 only translates lane-local coordinates into the final mark-band frame and projects them once. It MUST NOT rewrap, remeasure, choose another rung, rerun `resolve_text_visual_requests` on these pre-reserved lane labels, or copy an automatic placement coordinate. The final Scene text and ICON primitives carry the same `lane_row_id`/`lane_member_id` as their bundle and enter #467's Scene-footprint audit and #466's phase-one required-label obstacle set before routing.

For leading and trailing visuals, preserve the existing text-visual ordering and advance/gap rules. Title and selected delta form one required text run under the approved lane-label policy; the icon advances lie outside that run on their declared sides. The natural ladder row height is the maximum of measured text line block and placed icon extent plus declared padding. Visible overflow retains the complete text+icon bundle and diagnostic; it cannot suppress a packed name or silently omit an icon. A repeated source in two Review projection instances gets separate label/icon IDs and placements. Mark-target `iconMark` uses the separate [typed emission-group correction](issue-467-b1b2-s2b-icon-emission-closure-correction-2026-09-27.md); the common icon emission facts may be reused, but mark and label collision ownership stay distinct.

## Failure and migration

View owns target/ref/side/decorative intent; Use Case closes asset reference/encoding; Theme and font metrics supply appearance measures; Layout owns candidate geometry, atomically selected label+icon placement and route obstacles; Scene projects; adapters serialize. Existing `E_LAYOUT_VISUAL_DUPLICATE`, `E_LAYOUT_VISUAL_TARGET`, icon/Theme/metric diagnostics remain. A lane label target that cannot map to a unique projected member fails with `E_LAYOUT_VISUAL_TARGET`; a mismatch between pre-reserved and emitted bundle bounds fails before Scene with `E_LAYOUT_LANE_LABEL_VISUAL_UNAVAILABLE` and the source/member path. No after-the-fact Scene repair. Automatic/explicit paths and public bytes stay unchanged. The change is internal Layout data-model/algorithm work plus generated lane evidence, not a new View or Scene schema field beyond the separately approved lane provenance/anchor fields.

## Acceptance evidence

Focused tests cover leading/trailing/both sides, title+delta, multi-line/visible-overflow, vector multi-path and raster viewport, exact stroke once, duplicate side/unknown target, repeated source instances, attached points, rung/lane shift due component collision, all component geometry and source IDs preserved through preflight→B2→Scene, and no required-label route crossing. Public lane Scene/SVG inspection proves text and icon together; automatic byte characterization and a batched 28-slide materializer check prevent regression. The no-redundant-lane Scene audit still decides whether any conservative geometry produced a needless lane; no numeric target or third-row forcing is introduced.
