# Design — readable first run (#504, #501)

Follows the [design plan](../planning/active/issue-504-501-readable-default-design-plan-2026-09-29.md); the [architecture review](../reviews/current/issue-504-501-readable-default-architecture-review-2026-09-29.md) checks this decision. Living contracts are amended in Specs 08, 38, and 50.

The bundled readable default uses `automatic` rows with an item `Task` and planned-date table, while retaining Editorial-derived paint, plot names, row guides, and relations. This is #504's expressly allowed alternative to 26 semantically empty singleton lanes, and a scoped correction to #467's packaged-default migration. Authored lane Views and the reference-faithful Editorial gallery remain lanes. A diagnostic automatic-row render with the same HALCYON selection and semantic relations gave 23 visible names, three declared label suppressions, and no relation-suppression warning; this is feasibility evidence, not acceptance. The attached-point host must be visible in the real #486 `attached-milestones` starter even if its plot name cannot fit.

Packaged/committed lane Views that use `count: true` select the existing non-empty `lane` identity when a group header already names the group or no group exists. An explicit key or stable founder ID supplies that identity; `group` must not duplicate a first-lane header, and a multi-member lane must not borrow an arbitrary member title. Migrate the affected Views and their generated evidence together; membership, marks, and relation identities do not change. Public 03 is a separate #502 gate.

For dense lane slides, the existing Layout profile selects `rowDistribution: fill`. Layout measures finite stagger-label demand as part of each lane's minimum block requirement before surplus allocation and places names only in final rows. Suppression is legal only after proving that a lane can use no more legal block extent: its final extent reaches the host allocation limit or the maximum useful extent of every bounded candidate. Record lane ID, final extent, maximum useful extent, and limiting reason; report blocker geometry only secondarily. Do not retry in Scene or alter data-only lane membership. Corpus coverage derives shown/packed per committed lane Scene: distinct `laneMembers.memberId` in the denominator; distinct members with visible completed member/attached-name Text in the numerator. Group/synthetic labels and duplicate names never count.

The default Theme gives `calendar-closed` a faint fill without per-day stroke; the legend key uses the same role. Layout computes a shared mark-aware scale for fixed-lane preflight and final composition. The View-selected Date domain stays unchanged, but the usable range reserves the maximum left/right extents of every selected planned/Actual point facet, including resolved glyph, rotation and stroke. The scale origin is the inner range start; axes, calendar intervals, marks and labels use this same scale. No point facet means no inset. A non-positive inner range raises `E_LAYOUT_MARK_OVERFLOW`, never silently clips. Tests must prove date mapping, axis/window alignment, and preflight/final identity.

The as-of label stays on the plot side, outside every axis lane; current starter/HALCYON behavior needs a regression gate. End-side member-name search caps the gap from its own mark bounds to completed Text bounds at `2 × textLayout.fontSize`; then try start-side, then typed suppression/count. Layout owns measurement, scale, placement and diagnostics; Scene only projects completed geometry and source identity; adapters serialize it.

The first-run gate renders the actual bundled default on freshly initialized starter and bare HALCYON. It rejects `W_LAYOUT_*` except `W_LAYOUT_ACTUAL_INCOMPLETE` and `W_LAYOUT_LABEL_SUPPRESSED`, checks mark containment, closed-day/legend paint, as-of/axis separation, and source-matched name gaps. Inspect Scene and SVG output as well as relevant decoded PNG paint. The separate attached-milestones gate proves its host title in the table or plot in Scene and SVG. The default table will not have a universally missing Owner column. The optional row-following starter height is not yet decided: the existing Draft-auto 900px minimum makes it a canvas-sizing contract, not a local View adjustment.
