# Design Correction — Typed completed icon emission closure in lane facets (#467, #494)

**Plan:** [S2b icon design plan](../planning/active/issue-467-b1b2-s2b-icon-projection-design-plan-2026-09-27.md). **Corrects:** incomplete icon projection metadata in the [S2 source-keyed facet design](issue-467-b1b2-facet-count-asof-design-correction-2026-09-27.md). **Public base:** `10cc1fc9bd0c6a6119bc400294d811dce1a970bd`. The neutral facet currently carries completed commands/bounds/footprint but not all icon identity, normalized asset, paint or raster facts. B2 is forbidden to rebuild those from Theme/icon payload.

## Selected type and identity

Add an optional immutable `LaneIconProjection` value to each icon `LaneMarkFacet`. It is Layout-owned renderer-neutral emission data, not an adapter paint result. Common fields are `placement_id` (the one Scene ICON primitive ID), `icon_id`, `kind` (`vector` or `raster`), `asset_identity`, resource `viewport`, completed placed icon `bounds`, `visual_capability_source_ref`, `alternative`, `decorative`, `slot_id`, `paint_order`, and `stroke_scale` as provenance only. These are copied from the completed `IconPlacement`. A vector facet additionally carries `path_index`, `path_count`, and that completed `IconPathPlacement`'s `paint`, already-scaled `stroke_width`, `line_cap`, and `line_join`; its exact transformed commands remain in `LaneMarkFacet.completed_geometry`. A raster icon has exactly one facet with `path_index/path_count` absent and exact `raster_payload: bytes`; its viewport rectangle is both completed emitted geometry and collision footprint. Vector facets have no raster payload; raster facets have no vector path style. No asset load, alpha inspection, path transform or stroke rescaling occurs after this closure.

All vector path facets of one icon share `placement_id` and identical common metadata, with exactly one facet per index `0..path_count−1` and no duplicate/missing index. Their individual `primitive_bounds` and visible stroke-aware footprints remain separate and source-keyed for collision; the shared placed icon bounds do **not** replace them or become an extra footprint. The emission group is one existing Scene ICON primitive, not a synthetic facet. B2 groups completed facets by `placement_id`, validates the common fields and contiguous order, copies paths in index order into one `IconPlacement`/Scene ICON projection, and emits exactly one Scene primitive. It must neither parse the placement ID nor fetch the icon payload again. The ordinary `source_ref` and `projection_instance_id` remain distinct; repeated source objects in different Review instances have different `placement_id`s. The original Scene builder emits glyph parts as separate SYMBOL primitives, so this aggregate-emission rule applies to icons only.

## Ownership and failure

Theme/Icon Catalog and Layout's existing `complete_icon_paths()` select normalized resource facts and complete path coordinates/stroke scaling once. Layout's source-keyed facet closure retains both collision and emission facts atomically. The neutral allocator uses only each facet's visible footprint and overlay relation; it does not branch on icon paint or load resources. Scene invokes the existing paint resolver on the completed intents and projects the one icon primitive; adapters serialize. Missing asset identity/payload, invalid viewport or bounds, nonfinite/negative scaled width, unsupported kind/paint, inconsistent group metadata or path order fails before allocation with `E_LAYOUT_LANE_FOOTPRINT_UNAVAILABLE` or the stable underlying Theme diagnostic, not with an omitted icon or a late Scene repair. No public View/Theme/Scene schema change is intended; this is an internal Layout typed closure and B2 handoff.

## Evidence and migration

Implement an S2a-like type/validation slice before publishing S2b mapper: vector two-path fixture with distinct paint/cap/join and already-scaled widths, exact path order, duplicated/missing index rejection, mismatched asset metadata rejection, repeated projection instances, and one Scene ICON after B2 grouping. Raster fixture retains exact bytes and viewport with no alpha inspection. Tests assert that the 10× path envelope is collision-only, no second stroke scale occurs, and automatic/explicit Scene/SVG bytes remain unchanged while lane mode is guarded. If another compound emitted primitive is discovered during mapping, pause for design instead of generalizing this icon-specific rule ad hoc.
