# Design Amendment — Coincident Egress Port Identity (#466)

**Amends:** [anchor-port correction](issue-466-general-placement-anchor-port-correction-2026-09-26.md), [comparison egress correction](issue-466-general-placement-comparison-egress-correction-2026-09-26.md), and [connector topology correction](issue-466-annotation-connector-topology-correction-2026-09-26.md).

The O2 controller-z fixture revealed that `firmware-slip` exposes its annotation egress at the exact coordinate of an already registered relation endpoint port. The trial generated a new side-specific port ID that was not yet in the index, so a generic route query treated the *coincident existing endpoint port* as an unrelated obstacle and reported no route. Excluding the entire port class made a local route appear but would weaken the shared obstacle rule.

A connector trial therefore resolves its endpoint authorization **by identity and coordinate before routing**. The authorized set contains its own named registered port, plus registered port IDs that have the same normalized coordinate and belong to the same named connected comparison-host cluster as that endpoint. This is a finite, exact port-alias set, not an exemption of all ports for an object, row, route, or region. An unrelated port at the same coordinate is not authorized. The trial records the alias IDs; the accepted route still registers its selected semantic/exposed port. Other port obstacles remain active. Source and target aliases are handled symmetrically; a candidate may not borrow a port elsewhere on its route.

The alias rule lives in Layout's endpoint/port helper and is passed as explicit IDs to the shared obstacle query. Scene and adapters receive only the completed path. No View, Theme, or public schema change is needed. Focused tests must show the same-host coincident alias permits a local route, an unrelated coincident port remains blocking, and no blanket port-class omission occurs. Public controller-z/other materializer comparison and rendered inspection remain the O2 gate.
