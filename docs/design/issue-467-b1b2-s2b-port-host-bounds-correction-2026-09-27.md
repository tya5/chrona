# Design Correction — Semantic port host bounds on lane facets (#467, #494)

**Plan:** [S2b port-host design plan](../planning/active/issue-467-b1b2-s2b-port-host-bounds-design-plan-2026-09-27.md). **Corrects:** the port-containment invariant in the [S2 facet design](issue-467-b1b2-facet-count-asof-design-correction-2026-09-27.md). **Public base:** `6543b1c51233d1fa279b485d769d60fe961d06cc`.

## Use case and decision

Layout-completed `MarkPlacement` has a semantic mark-slot `bounds` and mark-level start/end ports. A Theme glyph can be contain-centered so its emitted part bounds are narrower than the mark slot; the legal ports then lie outside every emitted primitive part. Requiring a port inside a primitive's unexpanded bounds conflates semantic attachment with visible drawing and would force S2b either to falsify primitive geometry or create a non-emitted primitive. Both are rejected.

Keep each port source-keyed on one owning `LaneMarkFacet`, but add explicit `port_host_bounds` to that facet. The value is the completed semantic `MarkPlacement.bounds` in the same seed coordinate space as the facet. It is **not** the primitive bounds or visible collision footprint. Validate primitive commands against exact `primitive_bounds`, and separately validate every port position against `port_host_bounds`. A facet with ports must have valid, finite, ordered host bounds; a facet without ports carries no host bounds. Port IDs remain unique within the candidate; projection-instance and source identities remain exact. S2b assigns a semantic mark's ports and host bounds to its first emitted facet in stable primitive/part order; sibling glyph parts and comparison/progress/icon facets do not duplicate those ports. Attached points have their own completed mark and first owning facet. Missing host geometry fails with `E_LAYOUT_LANE_CANDIDATE_INPUT` before allocation, never with a synthetic facet or widened primitive.

The port host is copied from completed Layout geometry, not remeasured from View/Theme or Scene. It does not itself add a collision footprint; the mark's emitted facets and measured required text remain the collision authority. B2 projects the same completed port and primitive identities from the one lane plan. Relation/annotation routing uses the semantic mark port; it does not infer a replacement from the visible primitive boundary. No public View/Scene schema change, compatibility shim, adapter adjustment, or new user-visible policy is introduced.

## Evidence and migration

First amend the S2a internal facet validator and tests, then resume S2b mapping against the corrected contract. A 10×10 glyph fitted inside a wider 10..15 mark slot is a regression fixture: emitted part x≈12.1..12.9, legal ports at x=10 and x=15. The test must preserve exact part bounds and visible footprint, accept those ports through the host, reject a port outside that host, and reject a missing host. Add an attached-point port and repeated-instance identity fixture. Focused allocator/mapper/preflight tests and a batched public-materializer check establish no automatic output change. S2b remains separate from B2 composition and the fourteen-lane acceptance gate.
