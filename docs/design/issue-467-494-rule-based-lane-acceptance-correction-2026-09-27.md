## Selected rule and Scene identity bridge

The named `structure → avionics → bus-test` chain must share one lane. The 02 lane count is reported, never compared to 12, 14 or another target. On the completed 02 **Scene**, audit every unordered pair of lanes in the same group. For each direction, rigidly move all member footprints from one lane into the other's lane-local mark frame: preserve each footprint's inline/date coordinate and block offset relative to its source mark-band anchor, then align that anchor with the target mark-band anchor. Do not reallocate, resize, choose new label rungs or reroute in the audit. A pair is non-redundant only when a cross-member visible-footprint collision is measured in **both** directions, or when a separately approved enforced chain prohibition identifies the pair and its relation. Current predecessor preference is not a prohibition, so it cannot be used as an exception. Report tested pair IDs and at least one colliding primitive/member witness in each direction; a collision-free direction fails the criterion. The audit uses the same stroke and clearance policy as Layout's candidate test, including target-independent icon/path envelopes. Required labels/deltas are not exempt. Facets within the same countable member may intentionally overlay; they are not a reason to split lanes.

Scene primitives used in this audit need typed `lane_row_id` and `lane_member_id` provenance on lane-mode marks, comparison marks, required names/deltas and icons. The values are copied from the completed Layout lane plan; `ScenePrimitive.scene_id` supplies the primitive witness. Neither source-ref parsing nor spatial guessing from row bounds is acceptable, because repeated source instances and visible-overflow labels exist. Omit those optional fields in automatic/explicit output to preserve their bytes. Scene still carries only completed primitive geometry/paint and identity; it does not allocate, classify collision causes or infer chain rules. A read-only checker derives visible footprints from the emitted Scene primitive geometry and paint using the approved target-independent stroke envelope. If Scene geometry cannot reproduce an exact Layout footprint, return to design before acceptance rather than substitute Layout-only evidence. Scene v0.5 serialization/schema must admit the optional provenance fields in the B2 slice and preserve old-mode output.

## Per-group overlap reference and gap explanation

For each group, compute an exact endpoint-sweep maximum of simultaneously overlapping **primary mark occupancy intervals** read from Scene mark footprints, counting each root or attached member once. Use half-open intervals so touching endpoints may share a lane. The primary occupancy uses the planned span or point mark visible inline extent; comparison/Actual/icon facets of the same member are not additional members. Report this mark-only concurrency as the lower bound beside final lane count. This is a true one-dimensional lower bound for non-overlapping primary marks, not a target. Also report the maximum concurrent inline envelopes of each countable member's **full** Scene footprint set (marks, comparison, names, deltas, icons) as explanatory pressure, explicitly not calling that second value a mathematical lower bound: staggered labels occupy different block rows. Attribute any `final lanes − primary-mark lower bound` gap with concrete cross-lane collision witnesses from the pairwise audit, distinguishing primary marks, comparison/icon marks, required text and any enforced chain rule. A gap alone neither passes nor fails; no redundant lane and the other literal criteria decide acceptance.
