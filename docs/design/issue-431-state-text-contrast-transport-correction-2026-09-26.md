# Design Correction — State-Text Contrast Treatment Transport (#431)

**Corrects:** `issue-431-composited-role-contrast-design-2026-09-26.md`.

## Problem

The approved #431 design requires a completed-Scene report to evaluate both
state-text floors.  A state role's finite `contrastTreatment` is currently
validated at Theme closure, but is not carried by a completed Scene primitive.
The report would therefore have to guess a treatment from a role name or
silently select one fixed floor.  Either choice violates the boundary that
Scene policy uses completed facts only.

## Correction

`ScenePrimitive` gains an optional finite `contrast_treatment` field,
serialized as `contrastTreatment`.  The field is present exactly for a
semantic-registry `state-text` primitive and is the resolved Theme role's
`contrastTreatment` value (`required` or `deemphasized`).  It is absent for
unclassified primitives and decoration primitives.

The Scene model and schema reject an unclassified treatment, a classified
state-text primitive without one, and any non-finite value.  Scene projection
reads the treatment through typed `ThemeTokenView` access; adapters transport
the supplied field without interpreting it.

`scene.contrast_policy` may then map only the registry's classified completed
roles, use the primitive's treatment to select the fixed state-text floor, and
reject a missing or malformed field as `E_SCENE_STATE_TEXT_CONTRAST_TREATMENT`.
This is an evidence-integrity error, not a Theme closure substitute.

## Architectural consistency

This preserves the established ownership split: Theme closure still rejects
invalid authoring, Layout still owns geometry, Scene carries the resolved fact,
and the policy/report observes rather than reconstructs.  It adds no renderer
decision, role-name heuristic, numeric override, or second contrast formula.

## Migration and verification

The Scene schema and every affected generated Scene/SVG are regenerated by the
public materializer in the #431 release unit.  Focused tests prove the
state-only presence rule and exact serialized transport.  The report's
negative fixture proves that a missing treatment cannot be classified by
fallback.
