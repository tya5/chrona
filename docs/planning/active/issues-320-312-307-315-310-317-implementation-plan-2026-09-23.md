# Implementation Plan: Reachable, Safe, and Teachable Presentation Surface

## Preconditions

The merged design plan is `a46fa49`; the merged design review is `2cb07f1`.
Each slice below starts from current `origin/main`, is independently reviewed,
tested, and merged before its successor begins.  A discovered boundary change
requires a new published design correction before implementation resumes.

## I320 — truthful Quick Start and plan-only closure

CLI/integration tests, and generated artifact only if the example is declared

all existing materializers pass.

## I312 — Layout mark-capacity invariant

**Files:** `presentation/layout/presentation.py`, the Layout error boundary,
focused Layout/Scene tests, and output-property tests where appropriate.

**Change:** validate planned, actual, and missing-actual completed mark extents
against their allocated row tracks before marks are emitted.  Use one stable
`E_LAYOUT_MARK_OVERFLOW` diagnostic rooted at the resolved mark-size metric.

**Acceptance:** shared, stacked, actual, and missing-actual overflow cases
reject; boundary-sized marks pass; normal committed examples are byte-stable;
focused tests and full suite pass.

## I307 — remove the unreachable conditional-role seam

**Files:** `presentation/model/projection.py`, callers, and projection tests.

**Change:** remove unused `style`/`theme` projection parameters and the
conditional-rule branch.  Preserve only the fact-derived role mapping.

**Acceptance:** no call or contract accepts the deleted seam; role outcomes for
planned/actual/missing/variance/critical remain characterized; import and full
tests pass.

## I315-A — opacity delivery and literal-colour removal

**Files:** Theme schema/typed token access/resolution, semantic Theme fixtures,
Scene model and builder, SVG/Typst/TikZ renderers, renderer tests, public
themes, affected generated SVGs and materializer evidence.

**Change:** resolve role opacity as a finite `[0, 1]` Theme value, project it
through Scene, serialize or explicitly reject it per target, and delete
`ScenePrimitive.color`.  Create a tracked follow-up for #315's deferred paint
vocabulary before reporting this slice complete.

**Amendment (2026-09-23):** split `groupHeaderBand` from `groupBand` at the
semantic-registry visual-role boundary before moving alpha into Theme.  The
roles retain their current distinct policies (`group-band: 0.12`,
`group-header-band: 0.20`); Scene must not preserve that distinction with a
literal conditional.  See
`docs/reviews/current/i315a-group-opacity-design-correction-2026-09-23.md`.

**Acceptance:** zero/default/non-default/invalid alpha tests; no primitive
literal-colour field; every supported target has explicit behavior; public SVG
diff and materializer checks; focused and full tests pass.

## I310 — reachable inside labels with contrast

**Files:** `view-v0.8` schema, contract parsing/normalization, semantic
registry, Theme/Scheme contrast validation, Layout label composition, Scene
projection, tests, and one public example/evidence update.

**Change:** admit `inside` at every label-side ingress; keep fit/fallback in
Layout; emit an inside-label role only for a selected inside rung; validate the
role's contrast against eligible mark fills.

**Amendment (2026-09-23):** add the explicit `textOnMark` Scheme intent before
binding `memberLabelInside.fill`.  Existing Scheme intents cannot safely meet
the all-eligible-mark contrast invariant.  See
`docs/reviews/current/i310-inside-label-contrast-design-correction-2026-09-23.md`.

**Acceptance:** schema positive/negative cases; successful inside label;
short-mark fallback; insufficient contrast rejection; no renderer policy;
public materializer and full tests pass.

## I317 — reachability inventories and gates

**Files:** new narrowly-scoped checker(s), source-controlled inventories and

**Acceptance:** deliberate fixture omissions fail with actionable identity;
declared staged exemptions pass; current source passes without broad allowlist;
both local conformance and CI run the gates; full suite passes.
