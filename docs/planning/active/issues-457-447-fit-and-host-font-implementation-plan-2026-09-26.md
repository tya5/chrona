No generated public output is modified merely to make tests green. Compare
generated bytes, inspect Scene/SVG/PNG as a batch, and record intentional
changes. Run focused pytest locally per slice and let CI perform the planned
full pytest/conformance on three OSes and newest-Python reproduction. Before
each push, fetch remote `main`, inspect staged diff and ahead/behind status;
never force push. The user-visible CLI and immutable path share one Layout
solution; no Draft-only fit patch is permitted.
