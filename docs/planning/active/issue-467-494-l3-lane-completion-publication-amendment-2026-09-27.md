## Cross-cutting gates

- Use the current published Project's `avionics-bustest: 4wd` and View v0.27. Recompute all lane and route measurements; old branch counts and generated artifacts are not acceptance evidence.
- Required packed names and selected deltas are phase-1 Layout obstacles. Semantic routes may not cross them, including an endpoint's own label. Never add an all-label or endpoint-label exemption to make a route appear successful. Keep declared bend/detour bounds; record a measured cause for each suppression.
- Preserve `automatic` and `explicit` output unless a separately published design correction authorizes a change. Geometry, route choice and text measurement stay in Layout; Scene and adapters cannot repair them.
- Before each push, fetch and inspect `origin/main`, staged/generated diffs and conflict risk; push serially, verify the remote commit, and inspect CI after material publication. Do not run a redundant full local suite when CI supplies the specified matrix.
- If implementation exposes an incomplete contract or a layer breach, stop that unit and publish a design correction, whole-architecture review, normative specification change where needed, and implementation amendment before resuming code.
