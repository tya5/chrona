# #504/#501 readable-default work record

## Published baseline and design plan

Public `main` is `5408ef2d`; its bundled default selects the Editorial-derived View with lane mode, `[explicit, attached]` packing and `laneTable: {label: group, count: true}`, the Editorial Layout with `rowDistribution: pack`, and the readable-default Theme with outlined `calendar-closed`. A fresh unflagged render of HALCYON produces 26 singleton lanes, 26 empty Lane cells, 26 visible member names and three suppressed relation warnings. A fresh `chrona init` render produces three empty Lane cells, 79 outline-only closed-day rects, and a 34px planned release symbol at inline 1563–1597 outside the timeline's 1580 end. Its `TODAY` label is now at block 177.8–197.4, below the axis slot's 160.3 end, so the older as-of observation is not reproduced on this base; a regression gate is still needed. Committed 02 evidence has eight 30px lanes, 14 suppressed names, and a 954px timeline with unused height. #498's existing gate checks names/suppression but not table meaning, endpoint containment, or as-of/closed-day appearance. #434 already provides a declared `fill` Layout policy. [#502](https://github.com/tya5/chrona/issues/502) has an overlapping group-less lane-table requirement; its independent public-03 acceptance must not be silently counted complete. #526 precedes release work because main CI is red.

Literal [#504](https://github.com/tya5/chrona/issues/504) acceptance (including its later host-name comment):

1. The bundled default and the `chrona init` starter keep an informative table under lanes. Where a lane holds one item, the lane label is that item's name. Otherwise the default View does not use lanes. Either way, no table column is empty on every row. The #498 gate is extended to assert this. The host of attached points keeps a visible name, in the lane label or in the plot.
2. Lane height can grow into available plot height for stagger rows before a name is suppressed, as a declared Layout policy, for example with `rowDistribution: fill` (#434). A name is suppressed only when the lane cannot grow. On 02, the suppression count is reported in the acceptance review, and every suppressed name is attributed to a lane that could not grow.
3. The lane table does not repeat the group header's text on the group's first lane, and it never shows an empty label next to a count.
4. A mechanical check over committed lane slides: the ratio of shown to packed names is reported in the corpus coverage, so a regression is visible.

Literal [#501](https://github.com/tya5/chrona/issues/501) acceptance:

1. **Gate.** A test renders the bundled default on the `chrona init` starter and on HALCYON-1. It fails on any `W_LAYOUT_*` diagnostic other than data-state ones (`W_LAYOUT_ACTUAL_INCOMPLETE`, `W_LAYOUT_LABEL_SUPPRESSED`), and on any mark whose bounds leave the `timeline` slot.
2. Closed days render as a faint fill without per-day outlines, or as merged runs, in both the chart and its legend key.
3. The as-of label sits outside the axis lanes: in the plot's top margin, or as a chip on the rule.
4. Point marks on the domain's first or last day are fully inside the plot.
5. An end-side member label is placed within a bounded distance of its mark (a few em). Past the bound it takes `start`, or is suppressed and counted. A Scene check measures the gap.
6. Optional: the starter's plot height follows its rows, and a column whose source is missing on every row is omitted or declared.

Design questions: what lane table policy provides a unique singleton title without inventing a representative for multi-member lanes; how to avoid group-header duplication and blank counted rows; how `fill` interacts with minimum row height and bounded label search; whether optional starter polish can be included without coupling it to architecture fixes; where marker label and endpoint bounds should be completed; and how to prove SVG/Scene output instead of Scene-only claims. Whole-architecture review must check Specs 06/07/08/33/38/39, #467 lane membership, #488 row-band labels, #498 default policy, and #434 `fill` before implementation. Intended public evidence: starter, bare HALCYON, 02/03/11/12, attached-milestones, corpus coverage and generated SVG/Scene diffs. Design slices: table/row policy, closed-day paint, as-of/endpoint/label geometry, then corpus and first-run gate. Each slice must be independently reviewable and publishable.

## Selected core design

The bundled default returns to `automatic` rows, with meaningful item-level `Task` and planned-date columns and the existing plot-name/guide styling. This is the clean alternative expressly allowed by #504: 26 unrelated items should not be presented as 26 singleton lanes. It is a scoped correction to #467's packaged-default migration, not a rollback of lane mode or its data-only membership contract; authored lane Views and transit-map presets remain lanes. A diagnostic render with the same 26-item selection, automatic rows, plot labels and semantic relations shows 23 names plus three declared suppressions, with no relation-suppression warning; its table contains actual titles and dates. The attached-point host must be table-named even when its plot label cannot fit, proved separately on the actual #486 `attached-milestones` starter. This changes only the dedicated readable default, not the reference-faithful Editorial catalogue.

Generated lane Views with `count: true` must select a non-empty lane identity, not `group`, whenever a group header already names the group or no group exists. Use the existing `lane` policy (authored explicit key or stable founder ID), never a representative member title for a multi-member lane. Migrate affected packaged and committed lane Views as a batch; keep membership, mark and relation identities unchanged. The default's automatic table is separately checked for no universally empty column. This also covers #502's policy requirement, but #502 retains its own public-03 acceptance gate.

For lane slides with meaningful spare block space, select the existing Layout Profile `rowDistribution: fill`. Layout includes finite measured stagger-label demand in per-lane minimum block requirements before surplus distribution, then places names in final rows. A terminal suppression must prove the lane cannot use more legal block extent: the final allocated extent has reached the host's available extent or the maximum useful extent of every bounded label candidate. Only after this proof may blocker geometry be reported as a secondary cause. The decision records lane ID, final extent, maximum useful extent, and limiting reason; no membership or Scene-side retry occurs. The 02/11/12 profiles and generated output prove the policy, including an exact suppression count and each surviving attribution. Corpus coverage reports shown/packed by each committed lane Scene: denominator is distinct packed `laneMembers.memberId`; numerator is distinct members with a visible completed member/attached-name Text primitive, never a group header, synthetic lane key, or duplicate label. The generated report and its `--check` gate use the manifest's committed slide set.

The default Theme paints `calendar-closed` with the existing faint fill token, no per-day stroke; the legend swatch uses the same role. Layout shares one mark-aware scale between fixed-lane preflight and final composition. Its Date-only domain remains the View-selected window. For every selected planned/Actual point facet, including resolved glyph/rotation/stroke bounds, Layout computes left/right extents relative to the date anchor and reserves their maxima at the corresponding usable-range edges; absent point facets need no inset. The scale range is the inner interval, origin equals its start, and every date maps through that single scale, including axes and calendar intervals. A non-positive usable interval fails deterministically with `E_LAYOUT_MARK_OVERFLOW`, never adapter clipping. Tests check forward date mapping, axis/window interval alignment, and preflight/final scale identity. The as-of label must remain within the plot-side seam/slot and outside axis-lane geometry; current starter and HALCYON already do so, and the first-run gate protects it. End-side member-name search caps the horizontal free space between its own mark bounds and completed Text bounds at two times that Text's `textLayout.fontSize`; a start-side candidate is tried next, then typed suppression/count. Layout owns measurement/search, Scene carries completed text and source identity, SVG/PNG only serialize.

The #501 gate renders the actual bundled default on freshly initialized starter and bare HALCYON. It rejects every `W_LAYOUT_*` except the two specified data-state/suppression codes, checks every mark against the timeline slot, compares closed-day chart/key paint and as-of label versus axis geometry, and checks source-matched label gaps in em. Inspect SVG as well as Scene for the closed-day chart/key fill, the TODAY/axis boundary, the first/last point symbol, and member text positions; decoded PNG is checked where paint equality needs it. A separate #504 gate renders the real `attached-milestones` project and asserts the `campaign` host title is visible in its table cell or plot text in Scene and SVG. The optional starter-height/source-column criterion is tracked separately while its release disposition is confirmed with the owner: the source-empty Owner column can be removed by the new default table, but shrinking the 900px Draft-auto minimum is a wider canvas-sizing contract, not a local View patch.

## Whole-architecture review

Specs 06/38 keep View as the owner of row mode, selection, table policy and label intent; #467's data-only lane membership and #502's no-arbitrary-representative rule remain intact. The automatic readable default is the #504-specific correction to #467's earlier preset migration, not a generic automatic fallback. Specs 33/50 and #434 keep row minima, surplus allocation, text search, scale and diagnostics in Layout; #488's row-local name rule remains a hard bound. Spec 07 owns closed-day paint and legend parity; Spec 08 requires Scene to project completed geometry and adapters to serialize it. The selected design introduces no domain-data or adapter repair, no silent compatibility branch, and no new public schema syntax. Amend living Specs 38/50 for label-demand growth and suppression attribution, and Spec 08 for the inset completed scale range. Materializer byte changes in affected Views/Theme/Layout are intentional and must be reviewed by Scene/SVG plus rendered image batches. Remaining risk before implementation planning: prove the shared scale inset does not desynchronize lane preflight or axis intervals, and decide the optional starter-height disposition without weakening the five mandatory #501 gates.
