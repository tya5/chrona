# Design Plan — readable first run (#504, #501)

Public base: `5408ef2d`. [#504](https://github.com/tya5/chrona/issues/504) and [#501](https://github.com/tya5/chrona/issues/501) are open. #526 is the P0 release gate. The selected behavior is in the [design](../../design/issue-504-501-readable-default-design-2026-09-29.md); its cross-architecture check is in the [review](../../reviews/current/issue-504-501-readable-default-architecture-review-2026-09-29.md).

## Published baseline

The bundled default has lane rows with `[explicit, attached]` packing, `laneTable: {label: group, count: true}`, `rowDistribution: pack`, and outline-only `calendar-closed` paint. A fresh HALCYON render has 26 singleton lanes, 26 blank Lane cells, 26 visible member names, and three relation-suppression warnings. The initialized starter has three blank Lane cells, 79 outline-only closed-day rectangles, and a release symbol spanning 1563–1597 beyond the 1580 timeline edge. Its `TODAY` label is now below the axis, so the earlier axis collision is not reproduced and needs a regression gate. Committed 02 has eight 30px lanes, 14 suppressed names, and a 954px timeline with spare height. #498 checks names but not table meaning, endpoint containment, or calendar paint. #434 already declares `fill`; #502 independently requires group-less lane-table evidence on public 03. These observations are public-code reproductions; alternative automatic-row results are diagnostic, not released artifacts.

## Literal acceptance

### Issue #504

1. The bundled default and the `chrona init` starter keep an informative table under lanes. Where a lane holds one item, the lane label is that item's name. Otherwise the default View does not use lanes. Either way, no table column is empty on every row. The #498 gate is extended to assert this.
2. Lane height can grow into available plot height for stagger rows before a name is suppressed, as a declared Layout policy, for example with `rowDistribution: fill` (#434). A name is suppressed only when the lane cannot grow. On 02, the suppression count is reported in the acceptance review, and every suppressed name is attributed to a lane that could not grow.
3. The lane table does not repeat the group header's text on the group's first lane, and it never shows an empty label next to a count.
4. A mechanical check over committed lane slides: the ratio of shown to packed names is reported in the corpus coverage, so a regression is visible.

The [owner's later comment](https://github.com/tya5/chrona/issues/504#issuecomment-5871254241) extends row 1 to the actual attached-milestones host: it must retain a visible name in the lane label or plot. This is additional acceptance evidence, not a replacement for the literal body text.

### Issue #501

1. **Gate.** A test renders the bundled default on the `chrona init` starter and on HALCYON-1. It fails on any `W_LAYOUT_*` diagnostic other than data-state ones (`W_LAYOUT_ACTUAL_INCOMPLETE`, `W_LAYOUT_LABEL_SUPPRESSED`), and on any mark whose bounds leave the `timeline` slot.
2. Closed days render as a faint fill without per-day outlines, or as merged runs, in both the chart and its legend key.
3. The as-of label sits outside the axis lanes: in the plot's top margin, or as a chip on the rule.
4. Point marks on the domain's first or last day are fully inside the plot.
5. An end-side member label is placed within a bounded distance of its mark (a few em). Past the bound it takes `start`, or is suppressed and counted. A Scene check measures the gap.
6. Optional: the starter's plot height follows its rows, and a column whose source is missing on every row is omitted or declared.

## Decisions, dependencies, and evidence

Decide the singleton/multi-member table identity without inventing a representative; group-header duplication; `fill` versus measured label demand; point-bound scale inset and preflight/axis consistency; bounded member-name search; and the optional starter-height disposition. Review Specs 06/07/08/33/38/39/50 and #467/#488/#498/#434 before code. Design slices: table/row intent, lane growth, closed-day paint, mark/label geometry, then first-run and corpus gates. Each must have an independently reviewable public boundary. Evidence: starter, bare HALCYON, 02/03/11/12, attached-milestones, Scene/SVG and relevant PNG, corpus report, and generated byte diff. The optional item remains unresolved; do not treat the implementation plan as final until its release disposition is settled.
