## I478-1 — Typed information transport and Layout count

**Owners/files:** add a closed immutable information model under `src/chrona/presentation/model/`; extend `layout/surface_quality.py` and `layout/surface_composer.py` to count suppressed `memberLabel` placements after fallback; carry the typed fact through `scene/model.py`, `scene/v05_builder.py`, `usecases/render_review.py`, and `app/cli.py`. Preserve individual `W_LAYOUT_LABEL_SUPPRESSED` diagnostics. Scene serializes one deterministic `I_LAYOUT_PLOT_LABELS_SUPPRESSED:surface=<id>;count=<n>` per positive-count surface, and CLI emits one `severity: info` JSON line; adapters receive no policy. Do not emit a primitive for suppressed text.

**Focused tests:** Layout count exactly equals per-ID warnings for zero, one and multiple suppressions, including a table retaining all names; placement-to-Scene projection; Scene v0.6 serialization; CLI stderr info; no drawable suppressed Scene IDs. **Public evidence:** regenerate all 21 materializers in one batch, inspect Scene diagnostic diffs and representative SVG/PNG images. **Gate:** focused tests, public materializer `--check`, applicable conformance, then the CI full matrix if the slice is considered releasable. Publish code/evidence first; after remote/CI verification, publish the slice review separately before starting the next product slice.

## I478-2 — Profile-omission disposition

**Owners/files:** `scene/paint.py` returns completed paint plus typed optional-omission facts; `scene/v05_builder.py` deduplicates by role/treatment/profile/target and passes facts without altering primitive geometry; `scene/visual_capabilities.py` owns ordered same-target profile suggestion; `model/info_diagnostics.py` and CLI/inspection projection carry exact source pointer and public info fields. Add target-kind information to the resolved profile or builder input explicitly; never guess it from a baseline profile ID. Required unsupported effects continue to reject before adapter output. `elevated-light` baseline must name both group-band gradient and shadow, suggest v0.6 SVG/PNG appropriately, and produce no repeated fact per band. Rich profile emits neither omission and paints both treatments. `planned` mark shadow is treated as supported and tested under rich profile.

**Focused tests:** profile selection matrix including no same-target rich profile; malformed/incomplete/required fidelity unchanged; deterministic omission order/dedup; baseline/rich SVG and PNG Scene/CLI behavior; actual adapter output for rich group-band and mark shadows. **Public evidence:** batch all 21 materializers, classify new diagnostic-only bytes separately from any SVG bytes, and inspect representative before/after images. **Gate/publication:** focused tests, public checks and CI matrix; publish implementation/evidence, verify remote/CI, then publish the slice review separately.
