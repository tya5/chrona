## Required invariants and review checks

- Hash raw Context bytes before parsing. The file copied into the local closure must have identical bytes; emitted Context content identity equals the raw-file digest.
- Compare parsed Context trees before/after materialization. No locator, `store`, `revision`, `contentIdentity`, or other nested authored value is mutated, including package icon catalogs.
- Overlay entries are immutable for one materialization and keyed by full original reference or locator identity. Verify each copied payload before registration and on read. Reject overlay key misses/mismatches; do not substitute provider output or system fonts to complete a declared materialized closure.
- Keep the standard Revision Store and provider access contracts responsible for source resolution; materializer owns collection and transient overlay lifetime. Layout/Scene/adapters do not learn about providers or temporary paths.
- `render_review` defaults to Context identity revision for closure-local assets; explicit `asset_root` remains an explicit caller override. Test equal and divergent Project/Theme token cases.
- Check every context/resource consumer via corpus inventory and public materializer manifest rather than assuming all 15 have identical assets. Preserve actual, frozen baseline, historical captures, and Theme pins.
