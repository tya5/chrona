# Title Card: the reference elements chrona does not express (#429 row 4)

The `titlecard` catalogue preset references the packaged design `src/chrona/resources/designs/titlecard/` in place with the shared generic View `presets/bundles/design-default/view.yaml`. This report names every difference between the preset's rendered slide and its generated reference, with the capability each would need. Reference: [titlecard-target-2026-09-26/02-programme-board.png](../research/presentation/titlecard-target-2026-09-26/02-programme-board.png) (1600 x 900 hand-drawn mock; not chrona output). Render: `chrona render --preset titlecard examples/halcyon-1/project.yaml --actual examples/halcyon-1/actual.yaml --format png` at `cdf6b4b81`, and `examples/chrona-roadmap/project.yaml` for a second project (status ok). Both images were read directly; measurements are by eye unless a number is cited, and canvas heights are from the PNG header. Row pitch, pixel offsets and colour values are not measured.

Reading rule. The reference is the HALCYON mock (26 work packages in six groups); the draft render is halcyon-1 as the project stands (29 work packages, two `objectType` groups, `point` and `span`). The example slide `23-titlecard` reaches more of the reference because its own View names HALCYON's fields, window, periods and annotations. The preset's View is generic by design (#1492) and names no project value, so those rows are bundle-side choices, marked "bundle-side" below; they need no new capability.
